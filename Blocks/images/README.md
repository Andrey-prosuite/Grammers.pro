# Ресурсы интерфейса блоков

Здесь только изображения, принадлежащие интерфейсу блока: стрелки, иконки и подобные элементы. Контентные фото, макеты и скриншоты остаются в общей папке images/ или медиатеке WordPress. Не создавать копии контента для библиотеки.

- gallery-arrow-left.svg / gallery-arrow-right.svg — текущие стрелки горизонтальной галереи, перенесены без изменения геометрии. В разметке декоративные: alt=""; доступное название задаётся на button.

Пути относительно HTML страницы: ./Blocks/images/ из корня; ./images/ из Blocks/index.html. Визуальный каталог использует общие ресурсы, Vite обрабатывает их при сборке.

- cookie.svg — декоративная иконка компонента Cookie, alt="". Экземпляры явно используют этот общий ресурс интерфейса.
