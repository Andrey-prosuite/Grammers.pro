# Библиотека блоков

Новая страница [Brodeks](../brodeks.html) использует независимые копии последних текстовых экземпляров. [Карта и параметры](../docs/brodeks-story.md).

Обязательное различие: **компонент** хранится в библиотеке, **экземпляр** — отдельная копия в коде страницы. [Методика и обязательный выбор источника](METHODOLOGY.md). Общие CSS/JS ниже относятся к компонентам и каталогу; экземпляры получают свои классы, стили и контроллеры страницы.

Блок — первичная структура страницы: разметка, оформление и собственное управление. Модификация — независимый эффект, который подключается к библиотечному или произвольному блоку на странице. Сначала выбрать блок, затем его опции и нужные модификации.

[Открыть визуальный каталог](index.html) · [Инструкция агентам](AGENTS.md) · [Библиотека модификаций](../Modifications/README.md)

Каталог открывается двойным щелчком по `Blocks/index.html`, без сервера и Node.js. Это служебная страница с noindex, а не новая страница сайта. Примеры показывают исходные компоненты и общий механизм модификаций. На страницах размещаются независимые экземпляры; первые изображения/галереи пока используют прежнее общее подключение, Cookie уже разделена по методике.

## Устройство

```text
Blocks/
  README.md                         каталог и структура
  AGENTS.md                         использование и правила пополнения
  METHODOLOGY.md                     компоненты, экземпляры и порядок копирования
  index.html                        визуальный каталог рабочих вариантов
  blocks.scss                       единый исходник стилей блоков
  blocks.css                        результат Sass для прямого открытия HTML
  blocks.js                         единый JS блоков
  templates/
    single-image.html               четыре варианта разметки
    horizontal-gallery.html         четыре режима разметки
    cookie-notice.html               компонент уведомления
    text-summary.html               заголовок и описание
    text-tasks.html                 заголовок и задачи
    text-feature.html               крупный заголовок и узкая колонка
  images/
    README.md                       разделение интерфейса и контента
    gallery-arrow-left.svg          элемент управления
    gallery-arrow-right.svg         элемент управления
```

Один общий SCSS/CSS и один общий JS, секции с номерами и названиями. Не создавать отдельный CSS/JS для каждого исходного компонента и не копировать код модификаций внутрь блока. `src/styles/blocks.scss` пока содержит остальные блоки сайта; переносить их в библиотеку только в согласованном объёме. `styles.css` больше не содержит стили двух перенесённых блоков, поэтому `Blocks/blocks.css` подключается отдельно.

`templates/*.html` — фрагменты для страницы из корня проекта, не самостоятельные документы: выбрать нужный вариант, вставить и заменить контент. В визуальном каталоге пути начинаются с `../`, в корневой странице — с `./`. ID и селекторы экземпляров должны быть уникальными. Разметку можно прочитать прямо в раскрывающемся разделе каталога, шаблоны скачиваются отдельно.

Изображения контента остаются в общей `images/`, в будущем — в медиатеке WordPress. Здесь хранятся только собственные элементы интерфейса. Содержимое демонстраций не становится частью структуры блока.

## Подключение и проверка

Страница подключает `styles.css`, затем `Blocks/blocks.css` и `Modifications/modifications.css`. Скрипты defer: согласованный SmoothScroll, локальные GSAP/ScrollTrigger, `Modifications/modifications.js`, затем `Blocks/blocks.js`. Подробный пример — в [AGENTS.md](AGENTS.md). Только для статичных блоков достаточно базовых стилей; JS улучшает управление и подключает выбранные эффекты.

`npm run styles` собирает оба CSS. `npm run build` собирает четыре страницы сайта и каталог, сохраняя обычные локальные скрипты. `node --test tests/horizontal-gallery-input.test.cjs` проверяет контроллер галереи. После изменений обновить этот каталог, инструкции, профильные docs, собрать и проверить desktop/mobile. Коммит и push — только по команде пользователя.

[Рабочая выборка шторки](index.html#page-curtain) показывает последовательность на месте и переходы между настоящими страницами. [Механизм и тайминги](../docs/page-transition.md). Вся шторка — один page-transition.js до CSS, без атрибутов body и списка страниц; прямой вход и обновление тоже анимированы.

Галерея логотипов главной — независимый экземпляр clients-home из компонента02, режим scroll45s. [Подключение и настройки](../docs/home-clients-gallery.md).

Галерея наград главной — awards-home из экземпляра clients-home, scroll45s,7 исходных SVG. [Инструкция](../docs/home-awards-gallery.md).
