# Инструкция агентам: подключение и настройки модификаций

Этот файл описывает действующий интерфейс всех модификаций Grammers.pro. Читать вместе с корневым [AGENTS.md](../AGENTS.md). Каталог эффектов находится в [README.md](README.md); здесь приведено текущее поведение после согласованных изменений пользователя.

При добавлении, изменении или удалении модификации автоматически обновлять этот файл и связанные инструкции в рамках той же задачи, без отдельного напоминания пользователя. Записывать разметку, реальные настройки и значения по умолчанию, зависимости, адаптивность, доступность, очистку и совместимость. Не описывать несуществующие опции как готовые. Коммиты и push по-прежнему требуют явной команды пользователя.

## Где находится реализация

- [modifications.css](modifications.css) и [modifications.js](modifications.js): по одному общему файлу, одинаковые номера секций и русские комментарии. Глобальная шторка 13 по указанию пользователя вынесена целиком в один page-transition.js, в общих файлах остались указатели.
- [Blocks/blocks.scss](../Blocks/blocks.scss): оформление исходных компонентов; src/styles/pages/*.scss — экземпляры, src/styles/blocks.scss — остальные прежние секции. Не создавать отдельные файлы стилей каждого эффекта.
- [tokens.scss](../src/styles/tokens.scss): общие CSS-переменные.
- [case.html](../case.html), [index.html](../index.html), [cases.html](../cases.html): настоящие примеры. Отдельных демостраниц не создавать.
- `vendor/gsap.min.js` и `vendor/ScrollTrigger.min.js`: локальные библиотеки из закреплённого пакета GSAP 3.15.0. При обновлении пакета синхронизировать обе копии из `node_modules/gsap/dist`.

## Общее подключение

Общие ресурсы уже подключены один раз на всех трёх страницах. На новой странице сохранять этот порядок, включая `defer` и SRI SmoothScroll:

```html
<script src="./Modifications/page-transition.js?v=20261020-global-curtain-1"></script>
<link rel="stylesheet" href="./styles.css">
<link rel="stylesheet" href="./Blocks/blocks.css">
<link rel="stylesheet" href="./Modifications/modifications.css">
<script defer src="https://cdnjs.cloudflare.com/ajax/libs/smoothscroll/1.4.10/SmoothScroll.min.js" integrity="sha256-huW7yWl7tNfP7lGk46XE+Sp0nCotjzYodhVKlwaNeco=" crossorigin="anonymous"></script>
<script defer src="./Modifications/vendor/gsap.min.js"></script>
<script defer src="./Modifications/vendor/ScrollTrigger.min.js"></script>
<script defer src="./Modifications/modifications.js"></script>
<script defer src="./Blocks/blocks.js"></script>
<!-- Затем JS экземпляров текущей страницы, если он есть. -->
```

В реальных HTML сохранять актуальные версии запросов ресурсов. При смене версии JS синхронизировать `modificationsVersion` в [vite.config.js](../vite.config.js). Vite сам переносит библиотеки и общий JS в сборку; не править `dist/` вручную.

Контроллеры запускаются автоматически после готовности DOM. Не загружать общий JS повторно ради нового блока. `init()` повторно безопасен, но обычно не пересканирует уже инициализированный список элементов: после добавления или удаления экземпляров использовать соответствующие `destroy(); init();`. Исключения: делегированные GO-курсор и просмотрщик обслуживают новые цели без перезапуска. Единого `Modifications.init()` нет.

| № | Модификация | Включение | Контроллер | Зависимости |

## 01. GO-курсор

Добавить `go` существующей области, например `div.project-card__media`. Ссылку оставлять обычной; эффект не перехватывает клики. Служебный слой с кругом создаётся один на страницу, вручную его не добавлять.

| Настройка на `.go` | По умолчанию | Назначение |
| --- | --- | --- |
| `--go-cursor-unit` | `min(0.625vw, 10px)`, до 767px — `2.66667vw` | Единица размеров круга и стрелки |
| `--go-cursor-color` | `#242424` | Цвет круга |

```html
<div class="go" style="--go-cursor-unit: 10px; --go-cursor-color: #242424;">…</div>
```

Диаметр круга до масштаба — 10 единиц; видимое состояние `scale(.8)`, нажатие `.7`. Следование — 500ms `expo.out`, появление круга — 300ms `ease`. Это константы реализации, а не `data-*`-настройки. Стрелка белая. Инверсия отключена: `mix-blend-mode: normal`; прежние значения сохранены в комментариях CSS. Передача `--go-cursor-blend` в JS сама по себе инверсию не включает — активное CSS-правило эту переменную не использует.

Работает для fine pointer, touch отключён. Reduced motion убирает задержку и деформацию. Маска повторяет прямоугольник и скругления цели; сложные маски и повёрнутые области отдельно не поддерживаются. Настройки считываются при активации области. API: `GoCursor.destroy()` / `GoCursor.init()`.

## 02. Плавный скролл

Глобальная конфигурация SmoothScroll 1.4.10, отдельная разметка не нужна. Настройки меняются в существующем вызове `window.SmoothScroll({...})` секции 02 JS:

| Опция | Значение |
| --- | --- |
| `animationTime` | `800` ms |
| `stepSize` | `75` px |
| `accelerationDelta` / `accelerationMax` | `30` / `2` |
| `keyboardSupport` / `arrowScroll` | `true` / `50` px |
| `pulseAlgorithm` / `pulseScale` / `pulseNormalize` | `true` / `4` / `1` |
| `touchpadSupport` | `true`, сохранено по указанию пользователя |

В самой версии 1.4.10 `touchpadSupport` не распознаётся как опция; не обещать управление всеми тачпадами этим полем. При недоступном CDN остаётся нативная прокрутка. При reduced motion на запуске вызывается `SmoothScroll.destroy()`. Собственного контроллера `SmoothScroll.init()` в проекте нет; отключение библиотеки — `window.SmoothScroll.destroy()`.

## 03. SmartHeader

```html
<header class="site-header container uc-smart-header show-fixed-zero">…</header>
<main>…</main>
```

Поддерживается первая `.uc-smart-header` на странице. Следующий элемент получает `--smart-header-height` по измеренной высоте; в текущем шаблоне это `main`. `show-fixed-zero` — служебный класс видимого состояния, не дополнительный режим.

Пороги в JS: вниз скрывать при `scrollY >= 150`, вверх показывать при `scrollY >= 100`, до `50px` всегда показывать. Это координаты страницы, а не накопленное расстояние. Переход в CSS: `transform 1s cubic-bezier(.165,.84,.44,1)`. Порогов в `data-*` нет; для изменения править секцию 03 по задаче пользователя. Фон и поля используют `--color-background`, `--page-gutter`, `--container-width`; измеряемую `--smart-header-height` вручную не фиксировать поверх JS.

При клавиатурном фокусе внутри шапка видима; reduced motion отключает переход. `SmartHeader.destroy()` снимает слушатели/наблюдатель, показывает шапку и восстанавливает прежнюю переменную отступа; `init()` подключает заново.

## 04. Сжатие изображения карточки

Эффект включён CSS для существующей структуры `article.project-card` → ссылка при её наличии → `.project-card__media`. Не создавать вторую ссылку или специальную служебную обёртку.

От 960px hover с fine pointer уменьшает превью целиком до `.95`; переход `all .75s cubic-bezier(.16,.44,0,.97)`. Клавиатурный фокус также учитывается. На мобильном сжатия нет. Фон отдельно не увеличивается. Радиус внешнего превью задаёт `--radius-card` (25px).

Активное превью имеет обводку 1px `#e3e5e8` через `::after`; она действует также при мобильной эмуляции секции 05, не влияет на размеры и клики. Масштаб, обводка и длительность — CSS-константы секции 04, публичных `data-*`-опций и JS-контроллера нет. Reduced motion отключает сжатие и переходы.

## 05. ProjectPreview: длинный скриншот в карточке

Менять только существующую область изображения и её содержимое. Сохранить `article`, ссылку и заголовок выше по DOM.

```html
<div class="project-card__media go project-preview" role="img" aria-label="Превью проекта">
  <div class="project-preview__backdrop" aria-hidden="true"></div>
  <div class="project-preview__veil" aria-hidden="true"></div>
  <div class="project-preview__stage" aria-hidden="true">
    <div class="project-preview__screen">
      <img class="project-preview__screenshot" src="./images/projects/brodeks-screen.webp" width="900" height="2400" alt="" loading="lazy" decoding="async">
    </div>
  </div>
</div>
```

`--project-image: url(...)` на карточке задаёт фоновую фотографию; `src`, `width`, `height` у внутреннего img — настоящий длинный скриншот. Не добавлять логотип поверх фона. Если у кейса нет реального URL, не выдумывать ссылку; дать превью `tabindex="0"` для фокуса.

| CSS-переменная на `.project-card` | Обычный кейс | Featured от 960px |
| --- | --- | --- |
| `--project-screen-width` | `100%` | `calc(100% - 50px)` |
| `--project-screen-height` | `100%` | `100%` |
| `--project-screen-max-width` | `100%` | `900px` |
| `--project-screen-radius-start` / `--project-screen-radius-end` | `5px` / `25px` | `25px` / `0px` |

`project-card-featured` добавляется на `article`: отдельная строка сетки кейсов, изображение 85vh. До 959px featured снова 16:9, экран 100% без бокового зазора и радиусы 5→25px. Обычное превью всегда 16:9. `--project-preview-unit` на `.project-preview` отвечает за единицу тени, по умолчанию 1px; от 1024px — `min(100vw,1512px)/1512`.

Старт экрана: `perspective(1200px) translateY(0%) rotateX(7deg) scale(.85)`. Появление 750ms без задержки с кривой секции 04; уход transform/radius 850ms, opacity 150ms. Затемнение `rgba(8,8,7,.8)`. Первый проход скриншота — 12s `cubic-bezier(.25,.1,.55,1)` с задержкой 200ms; с 12.2s — цикл по 12s `cubic-bezier(.45,0,.55,1)` с `infinite alternate-reverse`. При выключении позиция сбрасывается. Эти значения меняются в CSS секции 05, отдельных атрибутов скорости нет.

До 959px JS выбирает только одну ближайшую к центру видимой области картинку в пределах ± её высоты; подпись не участвует. `data-project-preview-active` выставляет контроллер, не сохранять его в HTML. Неизменный выбор не перезапускает цикл. Текущие границы CSS: hover экрана от 1024px, сжатие секции 04 от 960px; клавиатурный фокус обрабатывается отдельно. Reduced motion отключает движение. `ProjectPreview.destroy()` / `init()` пересобирают мобильный выбор после изменения карточек; desktop hover остаётся CSS.

## 06. CaseVideo

```html
<video data-case-video autoplay muted loop playsinline controls preload="metadata" poster="./images/case/brodeks/overview-poster.webp">
  <source src="./images/case/brodeks/overview.mp4" type="video/mp4">
</video>
```

Опции — нативные атрибуты video: `autoplay`, `muted`, `loop`, `playsinline`, `controls`, `preload`, `poster`, `width`, `height`. JS не создаёт autoplay там, где он не задан. Reduced motion выключает автозапуск и ставит паузу; ручное управление controls доступно. При скрытии вкладки ролик останавливается, после возвращения возобновляются только игравшие ролики; ручная пауза при этом сохраняется. Отказ `play()` не скрывает контент. `CaseVideo.destroy()` снимает обработчики, ставит паузу и возвращает исходное значение autoplay; затем возможен `init()`.

## 07. CaseLayouts: вкладки, окна и автопрокрутка

| Метка | Где и зачем |
| --- | --- |
| `data-case-tabs` | Корень блока с вкладками |
| `data-tabs-mobile` | На корне: вкладки только до 1023px, выше видны обе панели; без метки вкладки действуют на всех ширинах |
| `data-case-tablist` | Контейнер кнопок с `role="tablist"` |
| `data-case-tab` | Кнопка с `role="tab"`, уникальным id, `aria-controls`, `aria-selected` |
| `data-case-panel` | Панель с уникальным id, соответствующим aria-controls кнопки |
| `data-screen-group` | Корень группы экранов без вкладок, как case-columns |
| `data-screen-scroll` | Ссылка `.case-shot` с вложенным `.case-shot__image`, разрешает управление циклом |
| `data-screen-hold` | Внутренний контейнер окон для паузы своей группы удержанием мыши |

Готовую структуру брать из `#case-responsive-preview`, `#case-pages-preview`, `#case-service-preview` в case.html. У нескольких экземпляров менять все ID и ARIA-связи. Без JS панели доступны, переключатели изначально скрыты атрибутом `hidden`. `data-screen-hold` размещать внутри корня группы: контроллер ищет его среди потомков.

Телефон `case-pair` прокручивается на всех ширинах; desktop пары, `case-pages` и `case-columns` — только до 1023px. Их desktop-изображения остаются длинными и статичными. Мобильный цикл такой же, как в секции 05: 12s + 200ms, затем с 12.2s по 12s туда/обратно. Уход из видимости и смена вкладки сбрасывают ход, удержание мыши сохраняет фазу. Короткий скриншот не прокручивается за свой конец. Без JS/reduced motion окна pages/columns можно листать вручную.

Параметры геометрии в blocks.scss: `--case-shot-height` (по умолчанию `min(clamp(360px,62svh,560px),100svh - 50px)`), `--case-layout-gap`; предел ширины — `--case-content-width` (1500px). Телефон сохраняет 318:673, не выше `100svh - 50px`. Это параметры оформления, а не JS-опции. Самих data-меток на произвольном div недостаточно: CSS движения связан с перечисленными классами и контейнером `container-type: size` для `cqh`.

`data-screen-running` на окне и `data-screen-paused` на группе — служебные состояния JS. Не задавать вручную. При скрытии документа, открытии просмотрщика и reduced motion движение отключается. Вкладки поддерживают стрелки/Home/End и roving tabindex. `CaseLayouts.destroy()` / `init()` обслуживают все группы, восстанавливают исходные атрибуты и очищают наблюдатели. Подробности: [case-blocks.md](../docs/case-blocks.md).

В текущем case-pages пять страниц: «Каталог», «Карточка товара», «О бренде», «Таблица размеров», «Дилеры». Во всех пока один тестовый layout-demo.webp, изображения заменяются независимо. До 1023px вкладки не сжимаются: доступна горизонтальная прокрутка списка без видимой полосы, выбор ArrowLeft/Right/Home/End выводит активную кнопку в видимую область списка, не прокручивая страницу. На десктопе список вертикальный. Для новой страницы добавить кнопку и панель с уникальной парой ID/aria-controls; остальные размеры и цикл назначаются общими классами и data-метками.

## 08. ImageViewer: увеличение выбранных изображений

```html
<a class="photo-zoom" href="./images/case/brodeks/cover.webp" data-image-title="Название изображения">
  <img src="./images/case/brodeks/cover.webp" width="1622" height="1005" alt="Описание изображения">
</a>
```

`photo-zoom` ставится на ссылку с img/picture, не на голый img. `href` — полный файл, `src` может быть миниатюрой; `alt` описывает изображение. `data-image-title` необязателен, по умолчанию подпись берётся из alt. `button.photo-zoom` тоже поддерживается, источник берётся из `img.currentSrc || img.src`. Старый `data-image-viewer` на a/button совместим. Динамические ссылки работают без переинициализации.

```js
ImageViewer.open({
  src: './images/case/brodeks/cover.webp',
  alt: 'Описание изображения',
  title: 'Подпись',
  width: 1622,
  height: 1005,
  opener: document.activeElement,
});
ImageViewer.close();
```

Обязателен src; остальные поля необязательны. opener — элемент возврата фокуса. Программный вызов размещать в JS, не в inline-обработчике HTML. Один dialog создаётся лениво. Закрытие: Esc, кнопка, фон или короткое нажатие на лист; перетаскивание не закрывает. Есть блокировка фона, удержание/возврат фокуса, загрузка/ошибка, обычный Ctrl/Cmd-клик. Без JS ссылка открывает файл. Vite переписывает локальные href обеих форм подключения.

Ширина листа до 1120px; увеличение с полями 16px. До 767px обычные поля 12px, увеличение до 200% с панорамированием. Затемнение/blur/переходы задаются в CSS секции 08; атрибутов для них нет. Reduced motion убирает переходы. API: `init()`, `destroy()`, `open(options)`, `close()`. Событие `image-viewer:change` на document с `detail.open` приостанавливает экраны и ленты. `destroy()` удаляет dialog, обработчики и блокировку. Подробности: [photo-modifications.md](../docs/photo-modifications.md).

## 09. PhotoParallax: параллакс фотографии

```html
<a class="photo-parallax photo-zoom" href="./images/case/brodeks/brand.webp">
  <img src="./images/case/brodeks/brand.webp" width="1680" height="1094" alt="Описание фотографии">
</a>
```

`photo-parallax` — на существующем контейнере с прямым img, picture или video. Можно использовать div без photo-zoom; эффекты независимы. Подпись размещать снаружи кадра. Размер, aspect-ratio и радиус задаёт сам блок; без явных пропорций сохраняется исходное соотношение размеров кадра. Указывать width/height медиа, в том числе для скрытых вкладок. Новые обёртки не создаются.

| Необязательная метка | Действие |
| --- | --- |
| `data-parallax-trigger` на внешней figure | Включает внешнюю область с подписью в путь ScrollTrigger |
| `data-parallax-media` на вложенном слое | Выбирает слой вместо прямого медиа; совместимость с прежней разметкой |
| `data-parallax-reveal` на кадре | Дополнительное раскрытие, если кадр уже видим при инициализации |
| `data-case-parallax` | Старый совместимый селектор запуска |

Движение: scale 1.05, yPercent -10→10, `top bottom` → `bottom top`, scrub true, ease none; обычное появление opacity за 1s. Для reveal: inset(5% 10%) → 0, scale .9→1 за 2.5s expo.out с задержкой .1s, opacity за 1s. Это константы секции 09, пользовательских атрибутов силы/скорости пока нет. Прямое медиа имеет запас высоты 125%, top -12.5%; `data-photo-parallax-ready` устанавливает JS, не писать его в HTML.

Требуются GSAP + ScrollTrigger до общего JS. Без библиотек остаётся видимая фотография. Reduced motion откатывает эффект. API: `PhotoParallax.destroy()` / `init()`; `CaseParallax` — совместимый псевдоним того же объекта. После добавления медиа использовать destroy/init. Очистка возвращает стили и служебные атрибуты. Подробности: [photo-modifications.md](../docs/photo-modifications.md).

## 10. CaseNext: следующий кейс и медиакурсор

```html
<section class="case-next" data-case-next aria-label="Следующий проект">
  <a class="case-next__link" data-next-link href="./case.html" aria-label="Следующий проект: название">
    <span class="case-next__track" data-next-track aria-hidden="true">
      <span class="case-next__word" data-next-word>Следующий проект</span>
    </span>
    <img class="case-next__source" data-next-image hidden src="./images/case/brodeks/cover.webp" alt="">
  </a>
</section>
```

Обязательны корень `data-case-next`, ссылка `data-next-link`, трек `data-next-track` и одно исходное слово `data-next-word`. Не дублировать слова в HTML — повторы создаёт ScrollReel. Указывать реальный URL проекта и осмысленный aria-label. Круг необязателен; источник — скрытый `img[data-next-image]` либо `video[data-next-video]` внутри блока. Если заданы оба, используется первый по DOM; обычно выводить один.

По умолчанию проход 15s; скролл × -0.3, минимум ±1, смена скорости 1s expo.out. Общий механизм читает `data-reel-scroll-duration` либо прежний `data-reel-duration`, если нужно явно изменить длительность. Режим case-next сохраняет согласованную реакцию на скролл; data-gallery-mode выбирает режим только у HorizontalGallery.

Круг появляется только для fine pointer без reduced motion, следует за мышью .5s expo.out; размер 360 единиц `--case-motion-unit`, деформация по отставанию указателя. Медиа видео в круге muted/loop/playsInline, запускается при наведении и ставится на паузу при уходе. Исходный DOM-источник не превращать в видимый второй плеер. Курсор создаётся в body и имеет собственную переменную единицы; переменная на case-next автоматически на этот слой не наследуется. Дизайн/цвет/геометрия — blocks.scss и CSS секции 10, атрибутов для них нет. Контейнер строки занимает всю ширину экрана без боковых полей и max-width, параметры букв и повтора сохранены.

Удержание мыши останавливает строку, сохраняя круг. Вне экрана, при скрытой вкладке и открытом просмотрщике движение останавливается. Reduced motion оставляет статичную ссылку без круга. `CaseNext.destroy()` / `init()` очищают строку, клоны, слой курсора, видео и обработчики. Подробности: [case-motion-blocks.md](../docs/case-motion-blocks.md).

## Общие помощники: не отдельные визуальные блоки

`MouseHoldPause.create(target, change)` находится в секции 07 до CaseLayouts. target — DOM-элемент, change получает true/false. Возвращает объект с `destroy()`. Используется экранами и case-next; галерея обрабатывает удержание в своём контроллере. Обрабатывает только левую кнопку мыши; отпускание вне блока, cancel, blur, выход из окна и скрытие документа снимают удержание. После удержания от 250ms или сдвига >6px завершающий click подавляется; короткий клик/клавиатура/touch не перехватываются. На время удержания запрещается нативный drag картинки. Не добавлять отдельные кнопки паузы.

`ScrollReel.create({root, viewport, track, items, manual, native, mode, onSuspend})` находится в секции 10 и используется CaseNext и библиотечным HorizontalGallery. native по умолчанию false: строка сохраняет transform, HorizontalGallery передаёт true и использует scrollLeft; возвращаемые setManual/isAutomaticScroll нужны общему управлению галереи. `items` — только исходные элементы; `manual` по умолчанию false (у галереи true); `mode` по умолчанию scroll; `onSuspend` — необязательный callback. Возвращает `{destroy, isPaused, refresh, setManual, isAutomaticScroll, getRestVelocity, wrapPosition}`. `ScrollReel.getOriginal(node)` возвращает исходную ноду для клона либо саму ноду — нужен просмотрщику для возврата фокуса. Глобальных `ScrollReel.init()` / `destroy()` нет; очищать созданный экземпляр. Не копировать этот механизм во второй файл для другого режима.

## Как вносить изменения дальше

1. Проверить актуальный код секции, корневые правила и этот справочник. Не указывать внешнюю атрибуцию эффектов или ссылки на их происхождение; технические лицензионные уведомления сторонних библиотек сохранять. Новое указание пользователя важнее ранее зафиксированных значений.
2. Подключать эффект к выбранным элементам явно. У фото photo-parallax и photo-zoom независимы; у карточек секции 04/05 связаны с существующей структурой. Не активировать все изображения сайта автоматически.
3. Не смешивать публичные настройки и служебные состояния. Не придумывать data-атрибут для параметра, который пока задан константой.
4. Поддерживать несколько экземпляров там, где они предусмотрены, уникальные ID, обычные ссылки, фокус, reduced motion и доступность без JS.
5. Автоматически обновить этот файл, каталог README и профильный файл docs при изменении интерфейса/значений. Для новой модификации добавить номер, пример, настройки, зависимости и API; при удалении убрать устаревшее описание. Историю действий вести в docs/HANDOFF.md, а не в этом справочнике.
6. После SCSS обновить styles.css через npm run styles; после HTML/CSS/JS выполнить сборку и проверку нужного поведения/адаптива. Для правок только документации достаточно проверки ссылок и git diff --check. Не создавать коммиты и не отправлять изменения без команды пользователя.

Горизонтальная галерея: видимая лента занимает всю ширину экрана, max-width:none; корень размещать вне узкой колонки/обрезающих предков. ## Одиночное изображение

Единый single-image заменяет одиночные case-media, case-cover и case-preview. data-image-layout: content (по колонке до 1500px, по умолчанию), inset (поля --image-gutter:40px), full (вся ширина), surface (серый фон с теми же внешними полями и картинка по центру до 1500px). data-image-zoom и data-image-parallax независимы, стандарт false; только true включает эффект. Нет отдельного контроллера. Обложка после заголовка — inset 40px, обе опции true, появление при загрузке сохранено. Инерция горизонтальной галереи: mouse drag затухает на 5% за условный кадр 60 Гц с учётом реального времени, без резкого snap. Статичные режимы замедляются до нуля без отскока; движущиеся плавно достигают штатной скорости ленты. Touch сохраняет браузерную инерцию: pointercancel не равен отпусканию, учитываются touchend и конец прокрутки. Возврат после native/обычного удержания — 1s expo.out от нуля. Автоматические длительности, реакция на скролл и шаг стрелок сохранены. data-gallery-inertia — служебное состояние, не записывать в HTML. Внутренний ScrollReel.setManual(value, smooth=false) при smooth=true возвращает скорость через 1s expo.out. getRestVelocity() даёт штатную native-скорость в px/ms, wrapPosition(value) переносит координату на эквивалентный участок бесконечной последовательности. Это помощники контроллера, не отдельные опции HTML.

Второй эффект появления single-image: data-image-appear="rise" — y 300px→0, opacity 0→1, 1s power1.out, один раз, когда верх figure достигает 85% высоты экрана. Использует существующий PhotoParallax секции 09, без нового контроллера/обёрток, reduced motion и очистка сохранены. Тестовый блок #case-usability-image: surface, zoom false, parallax false, appear rise. При запросе нового одиночного изображения уточнять и вариант появления, если он не указан.

## 13. PageTransition — глобальная шторка

Глобальная шторка: одно синхронное подключение `Modifications/page-transition.js` в head до CSS на всех страницах. Внутри CSS, ранняя маска и контроллер; GSAP общий или автоматически локальный vendor. Атрибуты body, список страниц и хранилище не нужны. Открытие действует также при прямом входе/обновлении. В WordPress подключать один раз через общую шапку темы. API PageTransition.init/destroy/preview; прежние тайминги, reduced motion, аварийное снятие и стабильная ширина сохранены. [Подключение и параметры](../docs/page-transition.md).

Одно подключение без defer/async до CSS; отдельные modifications.css/js для эффекта не нужны. Статические страницы содержат строку подключения в каждой head, общий шаблон WordPress — одну строку для всех. Любые внутренние HTML/адреса без расширения/каталоги и PHP работают без списка; ресурсы, внешние, якоря текущего документа, новые вкладки, download и модификаторы не перехватываются. data-page-transition-skip исключает ссылку; button[data-page-transition-preview] запускает пример. Не копировать эффект в JS экземпляров блоков.

Уход 700ms power3.inOut; main вниз20vw/blur15px power2.inOut. Открытие графита вниз700ms, подложка исчезает500ms со старта500ms, main y300→0/opacity0→1 за1s power1.out со старта350ms. Ресурсы первого экрана до5s; защита ранняя12s/вход8s/навигация5s. Это константы, не публичные data-настройки. Скрипт использует первый main, без него только шторка. destroy очищает события/таймеры/слои/inline/inert/overflow; общая таблица CSS остаётся. bfcache повторяет открытие; после завершения событие page-transition:ready. Без JS/reduced motion обычный контент, ошибка GSAP снимает маску. Постоянный html scrollbar-gutter:stable не ограничивать busy-состоянием.

Методика компонент/экземпляр: [Blocks/METHODOLOGY.md](../Blocks/METHODOLOGY.md). Проверки: node --test tests/page-transition.test.cjs tests/horizontal-gallery-input.test.cjs.

## 14. TextReveal — появление текстов

На произвольном корне data-text-reveal, на целях data-text-reveal-item. Заголовки статичны, если явно не помечены. data-text-reveal="false" отключает корень; вложенные корни независимы. Opacity0→1 за3s cubic-bezier(.19,1,.22,1), без смещения, один раз при top bottom каждой цели. Пункты li получают задержки по порядку0/.1/.2…s, прочие цели0; data-text-reveal-delay заменяет задержку числом секунд, невалидное значение возвращает автоматическое. Прочие параметры — константы, не data-опции.

GSAP/ScrollTrigger перед общим JS, секция14 CSS содержит только пояснение: без JS текст не скрыт. Reduced motion не запускает fade; ошибка создания возвращает исходные стили. При шторке ждёт page-transition:ready. TextReveal.init/destroy: повторный запуск безопасен; destroy удаляет ожидание событий, откатывает GSAP matchMedia/ScrollTrigger и opacity/visibility. После замены контента destroy/init. Не совмещать конкурирующие opacity-анимации на одной цели. Геометрия принадлежит блоку. Применён к компонентам04–06 и экземплярам Brodeks; [руководство](../docs/text-blocks.md), проверка node --test tests/text-reveal.test.cjs.
