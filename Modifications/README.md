# База модификаций

Практическая инструкция агентам по модификациям и их подключению: [AGENTS.md](AGENTS.md). Обновлять её автоматически вместе с изменением эффектов. Документировать текущие настройки и интерфейсы без внешней атрибуции; лицензионные уведомления сторонних библиотек сохранять.

## Файлы и правила

- [modifications.css](modifications.css) — общий CSS эффектов.
- [modifications.js](modifications.js) — общий JS эффектов.
- Блоки первичны: [библиотека Blocks](../Blocks/README.md), её [инструкции](../Blocks/AGENTS.md). Геометрия библиотечных блоков — Blocks/blocks.scss, остальные блоки — src/styles/blocks.scss; общие переменные — src/styles/tokens.scss.
- В CSS/JS каждый эффект имеет секцию «МОДИФИКАЦИЯ NN» с русскими комментариями и взаимной ссылкой. Отдельных файлов и демостраниц каждого эффекта не создавать. Согласованное исключение — глобальная шторка13: page-transition.js содержит весь эффект для одного подключения до CSS.
- Сохранять семантику, доступность без JS, уникальные ID/ARIA, клавиатуру, reduced motion, изоляцию экземпляров и очистку.
- Новые указания пользователя важнее ранее согласованных значений. Не менять параметры незатронутых эффектов.
- Изменения разрабатываются локально; коммиты и push — только по команде пользователя.

## Подключение

Все три страницы уже подключают общий CSS, согласованный SmoothScroll с CDN/SRI, локальные GSAP и ScrollTrigger, затем общий JS; обычные скрипты defer; единый page-transition.js подключается синхронно до CSS. Сохранять порядок на новых страницах. Полный head и описание зависимостей — в AGENTS.md. Обычный корневой HTML работает при открытии файлом; сеть требуется только для SmoothScroll.

После SCSS обновить styles.css; после изменения HTML/CSS/JS выполнить сборку. При смене версии ресурсов обновить исходные HTML и modificationsVersion в vite.config.js. dist/ вручную не редактировать.

## Текущие решения

GO-курсор: круг #242424, стрелка #fff, mix-blend-mode:normal. Прежние выключенные настройки инверсии сохранены в комментариях. Touch не подключается.

Сжатие карточки действует от 960px, на телефоне отключено. Обычное превью 16:9; featured от 960px занимает отдельный ряд и имеет высоту 85vh, экран максимум 900px без вертикального зазора. До 959px featured ведёт себя как обычная карточка. Радиус экрана 5→25px, у featured desktop 25→0px. Старт экрана perspective(1200px) translateY(0%) rotateX(7deg) scale(.85); появление 750ms. Первый ход скриншота 12s с задержкой 200ms, затем симметричный цикл туда/обратно по 12s; уход сбрасывает позицию. До 959px автоматически активируется максимум одна ближайшая к центру картинка. Фон отдельно не увеличивается.

Окна case-pages/case-columns до 1023px прокручиваются тем же циклом, что мобильный экран case-pair. На desktop их изображения длинные и статичные. Пауза удержанием мыши хранит фазу; при уходе/переключении вкладки цикл сбрасывается. Без JS/reduced motion эти окна листаются вручную.

Увеличение photo-zoom и параллакс photo-parallax независимы и сочетаются. Старые data-image-viewer/data-case-parallax/data-parallax-media совместимы. Лишние обёртки не создаются. Картинки без явного подключения не активировать.

Кнопок паузы нет: MouseHoldPause из секции 07 обслуживает циклические экраны и строку case-next, работает только во время удержания левой кнопки мыши. Горизонтальная галерея обрабатывает удержание и drag в едином контроллере Blocks/blocks.js. ScrollReel — общий помощник секции 10; не копировать его для новых режимов.

Горизонтальные галереи объединены: data-gallery-mode задаёт static, linear, scroll или controls. Мышь/touch/тачпад работают во всех режимах; цикл после ручного жеста продолжается от новой позиции. Стрелки могут быть внешними: CSS-селекторы кнопок задаются на корне. До 959px видны 20px следующей карточки. Примеры: концепция controls, мобильные экраны linear 60s, дипломы static, детали scroll 30s. Полные настройки: [horizontal-gallery.md](../docs/horizontal-gallery.md). case-next занимает всю ширину экрана без боковых полей контейнера.

Горизонтальная галерея: видимая лента занимает всю ширину экрана, max-width:none; корень размещать вне узкой колонки/обрезающих предков. Заголовки/описания ограничиваются отдельно. data-gallery-zoom="true" включает увеличение, по умолчанию false; обычные img поддерживают клик и Tab/Enter/Space без дополнительных обёрток, ссылки photo-zoom внутри галереи подчиняются опции. В текущих галереях увеличение включено только у «Деталей проекта».

При запросе нового блока галереи уточнять недостающие опции одним коротким вопросом: материалы, режим, скорость/длительность, зазор, размеры и радиус карточек, увеличение по клику, стрелки/их расположение для controls. Уже согласованные параметры повторно не спрашивать. Сохранять эти настройки в data-* и инструкции автоматически.

## Одиночное изображение

Единый single-image заменяет одиночные case-media, case-cover и case-preview. data-image-layout: content (по колонке до 1500px, по умолчанию), inset (поля --image-gutter:40px), full (вся ширина), surface (серый фон с теми же внешними полями и картинка по центру до 1500px). data-image-zoom и data-image-parallax независимы, стандарт false; только true включает эффект. Один кадр data-image-frame внутри figure, без дополнительных JS-обёрток и пустых ссылок. Параметры ImageViewer/PhotoParallax прежние, код эффектов остаётся в секциях 08/09. Нет отдельного контроллера. Обложка после заголовка — inset 40px, обе опции true, появление при загрузке сохранено. Полные примеры, CSS-переменные, адаптивность и очистка: [single-image.md](../docs/single-image.md). При новом блоке уточнять только недостающие опции; обновлять инструкции автоматически.

Инерция горизонтальной галереи: mouse drag затухает на 5% за условный кадр 60 Гц с учётом реального времени, без резкого snap. Статичные режимы замедляются до нуля без отскока; движущиеся плавно достигают штатной скорости ленты. Touch сохраняет браузерную инерцию: pointercancel не равен отпусканию, учитываются touchend и конец прокрутки. Возврат после native/обычного удержания — 1s expo.out от нуля. Автоматические длительности, реакция на скролл и шаг стрелок сохранены. data-gallery-inertia — служебное состояние, не записывать в HTML. Подробности в docs/horizontal-gallery.md; проверка: `node --test tests/horizontal-gallery-input.test.cjs`.

Второй эффект появления single-image: data-image-appear="rise" — y 300px→0, opacity 0→1, 1s power1.out, один раз, когда верх figure достигает 85% высоты экрана. Работает независимо от data-image-parallax и заменяет стандартное появление; отсутствие атрибута (auto) сохраняет прежнее поведение. Использует существующий PhotoParallax секции 09, без нового контроллера/обёрток, reduced motion и очистка сохранены. Тестовый блок #case-usability-image: surface, zoom false, parallax false, appear rise. При запросе нового одиночного изображения уточнять и вариант появления, если он не указан.

## Приоритет библиотек

Сначала выбрать блок в Blocks, затем применить модификации. Один и тот же эффект можно подключать к библиотечному или произвольному подходящему блоку страницы. Не хранить структуру блока как копию модификации. Одиночное изображение использует ImageViewer/PhotoParallax (08/09), горизонтальная галерея — ScrollReel (10) и опционально ImageViewer (08). После общего JS эффектов страницы подключают Blocks/blocks.js; базовые стили этих блоков — отдельный Blocks/blocks.css.

## 13. Переход между страницами

700ms закрытие сверху power3.inOut; main вниз20vw и blur15px power2.inOut. Затем обычная загрузка нового документа под ранней маской. После готовности важных ресурсов графит уходит вниз700ms, белый слой исчезает500ms со старта500ms; контент поднимается300px с opacity0→1 за1s со старта350ms. Все значения — константы, не дополнительные data-настройки. [Рабочая выборка](../Blocks/index.html#page-curtain), [инструкция](../docs/page-transition.md).

Глобальная шторка: одно синхронное подключение `Modifications/page-transition.js` в head до CSS на всех страницах. Внутри CSS, ранняя маска и контроллер; GSAP общий или автоматически локальный vendor. Атрибуты body, список страниц и хранилище не нужны. Открытие действует также при прямом входе/обновлении. В WordPress подключать один раз через общую шапку темы. API PageTransition.init/destroy/preview; прежние тайминги, reduced motion, аварийное снятие и стабильная ширина сохранены. [Подключение и параметры](../docs/page-transition.md).

При работе с блоками применять [методику компонентов и экземпляров](../Blocks/METHODOLOGY.md); общий эффект подключать явно к экземпляру, его код не копировать как индивидуальную логику страницы.


Место под вертикальную полосу прокрутки постоянно резервируется на html через scrollbar-gutter:stable. Это общее правило инфраструктуры страницы, а не состояние только на время busy: при overflow:hidden и его снятии ширина контента остаётся одинаковой. Для систем с накладными полосами дополнительный зазор не создаётся. Не переносить scrollbar-gutter только внутрь busy-селектора — это вернёт сдвиг после анимации. Тайминги и блокировка прокрутки сохранены.
