# База модификаций

Модификация — самостоятельный эффект на CSS и/или JS. Вся база хранится в двух общих файлах:

- [modifications.css](modifications.css) — стили всех эффектов.
- [modifications.js](modifications.js) — код всех эффектов.

Каждая модификация отделяется в обоих файлах заметной секцией `МОДИФИКАЦИЯ NN. НАЗВАНИЕ`, обрамлённой строками звёздочек. В комментарии секции — ссылка на секцию второго файла, назначение, разметка, подключение, настройки, зависимости и очистка. Все комментарии писать на русском. Разделы разных эффектов независимы; добавлять только нужный код. Базовые стили сайта остаются в `src/`.

## Алгоритм

1. Определить эффект и изучить указанный референс. Параметры считывать из CSS/JS, фиксировать источник; не подбирать похожие значения вместо доступных оригинальных.
2. Добавить секции в общие CSS и JS с взаимными ссылками и инструкциями в русских комментариях.
3. Проверять эффект на целевых элементах настоящих страниц сайта, включая мобильную и широкую ширину. Отдельные демостраницы не создавать.
4. Поддерживать независимые экземпляры, безопасную повторную инициализацию, доступность и reduced motion. Не мешать кликам и клавиатуре.
5. Обновить этот каталог. Коммиты и отправка в GitHub — только по явной команде пользователя.

## 01. Курсор внутри .go

Класс `go` включает круг со стрелкой вверх-вправо, плавным следованием, деформацией и появлением из точки. Применён к `.project-card__media.go` на главной и cases.html. Круг ограничен карточкой и её скруглениями, при уходе сжимается. Клики не перехватываются; системный указатель сохранён. Новые и вложенные `.go` поддерживаются без перезапуска.

```html
<article class="project-card"><a class="project-card__link" href="…"><div class="project-card__media go" role="img" aria-label="Превью проекта"></div><h2 class="project-card__title">Название проекта</h2></a></article>
```

Параметры из референса [Cuberto](https://cuberto.com/), считанные из опубликованных ресурсов:

| Параметр | Значение | Источник |
| --- | --- | --- |
| Длительность движения | 0.5 с, перезапись предыдущей цели | `index.astro_astro_type_script_index_0_lang.B2DOFWPC.js` |
| Кривая движения | `expo.out`; формула скорректированной экспоненты GSAP | `gsap.DWxn8li7.js` |
| Деформация | `min(hypot(targetX − x, targetY − y) × 0.001, 0.15) × skewing` | код Cursor |
| Масштабы по осям | `1 + деформация`, `1 − деформация` | код Cursor |
| Направление | `atan2(targetY − y, targetX − x)`; обратный поворот внутренней стрелки | код Cursor |
| Skewing | базовый 1.5 → 2 в состоянии со стрелкой, 0.5 с `power1.out` | код Cursor и стандартные параметры GSAP |
| Круг | размер 10 rem, масштаб `0 → 0.8`, при нажатии 0.7 | `Footer.v_lo1qnf.css` |
| Рост / сжатие | 0.3 с, CSS `ease` = `cubic-bezier(.25,.1,.25,1)` | CSS Cursor |
| Стрелка | 2 rem; прозрачность 0 → 1 за 0.4 с; масштаб 0 → 1 и поворот 10° → 0° за 0.3 с, `ease` | CSS Cursor |
| Наложение | `exclusion`, белый круг, чёрная стрелка | CSS Cursor |
| Единица размера | desktop `0.625vw`, максимум 10 px; до 768 px — `2.66667vw` | CSS html референса |

Ресурсы расположены под `https://cuberto.com/_astro/`; имена хешированных файлов могут измениться. Геометрия стрелки сверена с `https://cuberto.com/assets/sprites/svgsprites.svg#arrow-up-right`.

Формулы и значения воспроизведены локально без внешней библиотеки. Отличие по задаче: эффект действует внутри `.go`, а не по всему окну. До входа круг скрыт полностью; в референсе глобальный указатель сохраняется маленькой точкой. Это меняет начальное состояние, но не длительность и кривую роста.

CSS-переменные на `.go`: `--go-cursor-unit` меняет единицу размера, `--go-cursor-color` — цвет. По последнему запросу инверсия отключена: mix-blend-mode: normal, круг #242424, стрелка #fff для контраста. Исходное exclusion с --go-cursor-blend, белый фон круга и чёрная стрелка сохранены в комментариях CSS; JS-передача настройки blend сохранена для восстановления эффекта. По умолчанию размер соответствует референсу, а не зависит от базового rem Grammers.

Очистка: `window.GoCursor.destroy()`. Повторный запуск: `window.GoCursor.init()`. Сенсорный ввод отключён; при reduced motion нет задержки, деформации и переходов появления. Для повёрнутых, многострочных inline-элементов и нестандартных масок требуется дополнительная маска: текущая область обрезки — bounding rectangle со скруглениями.

## 02. Плавный скролл

SmoothScroll 1.4.10 подключён глобально на главной и cases.html. На всех следующих страницах использовать тот же общий head: CDN-скрипт с SRI перед `modifications.js`, оба с `defer`. В WordPress подключить библиотеку через enqueue и объявить её зависимостью общего файла модификаций.

Настройки пользователя сохранены: `animationTime: 800`, `stepSize: 75`, `accelerationDelta: 30`, `accelerationMax: 2`, `keyboardSupport: true`, `arrowScroll: 50`, `pulseAlgorithm: true`, `pulseScale: 4`, `pulseNormalize: 1`, `touchpadSupport: true`. Указанная контрольная сумма проверена по загруженному файлу.

Особенности самой версии 1.4.10: `touchpadSupport` отсутствует в списке распознаваемых опций, хотя передаётся по запросу пользователя; библиотека определяет события тачпада своим алгоритмом. Поддержку любого тачпада этот параметр не гарантирует. Библиотека сама ограничивает работу поддерживаемыми desktop-браузерами; мобильная прокрутка остаётся нативной.

Если CDN недоступен, сохраняется обычная прокрутка. При включённом reduced motion на загрузке страницы библиотека отключается. Локальные HTML, CSS, изображения и курсор доступны без сети, для плавного скролла требуется CDN.

## 03. smart-header

Применён к header главной и cases.html: `class="site-header container uc-smart-header show-fixed-zero"`. Шапка фиксируется сверху и видна при загрузке. При движении вниз скрывается от 150 px, при движении вверх показывается на координатах от 100 px; в зоне до 50 px всегда видна. Это координаты страницы, как в коде пользователя, а не накопленное расстояние прокрутки. Предыдущая координата обновляется и возле верха.

Переход: `transform 1s cubic-bezier(.165,.84,.44,1)`. Анимируется только transform. Фон непрозрачный, высота на desktop 90 px; на мобильном подстраивается под существующую навигацию. Отступ следующего main равен измеренной высоте шапки, чтобы контент не перекрывался и не прыгал при скрытии. Без JS шапка остаётся видна; мобильный резерв отступа задан CSS. При фокусе с клавиатуры шапка раскрывается и остаётся доступной; reduced motion отключает переход.

Работает совместно со SmoothScroll и нативной прокруткой. Зависимостей нет. Очистка: `window.SmartHeader.destroy()`, повторный запуск: `window.SmartHeader.init()`.

Мобильный запуск — секция 05 modifications.js, без зависимостей. Позиция пересчитывается через requestAnimationFrame по scroll/resize окна и visualViewport; ResizeObserver отслеживает размеры превью. У цикла fill-mode: forwards, поэтому он не перекрывает первый старт до окончания своей задержки. Появление маски не повторяется; reduced motion отключает анимацию.
