# Grammers.pro

Статическая вёрстка на Vite, Nunjucks, SCSS и обычном JavaScript с jQuery. Клиентский фреймворк не требуется: итог сборки — HTML, CSS и JS, пригодные для переноса в тему WordPress.

## Запуск

Node.js >= 22.12, npm.

```sh
npm ci
npm run dev
```

`npm run build` создаёт `dist/`. `npm run preview` позволяет проверить сборку. `dist/` не редактировать.

## Структура

- `src/layouts/` — общий HTML-каркас.
- `src/pages/` — композиция страниц из блоков.
- `src/data/` — контент страниц отдельно от шаблонов; сейчас `home.js`.
- `src/blocks/<name>/` — независимая секция: `<name>.njk`, `<name>.scss`, при необходимости `<name>.js`, точка входа `index.js`.
- `src/components/` — небольшие повторяемые элементы: кнопки, поля и т. п.
- `src/styles/` — токены, базовые правила и контейнеры; без стилей отдельных блоков.
- `src/scripts/main.js` — подключение блоков и их инициализация.
- `src/assets/{images,icons,fonts}/` — ресурсы, обрабатываемые сборщиком.
- `public/` — файлы, копируемые в сборку без обработки.
- `docs/architecture.md` — соглашения и план переноса на WordPress.

Пустые каталоги ресурсов появятся в Git после добавления файлов.

Встроенная главная — технический пример, а не утверждённый дизайн. Автотестов пока нет; сборка проверяет шаблоны и импорты. Секреты и внешние сервисы для запуска не нужны.
