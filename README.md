# Grammers.pro

Статические главная и страница кейсов на обычном HTML и SCSS, без шаблонизатора; локальный JS используется для курсора на карточках кейсов и настройки SmoothScroll 1.4.10 с CDN. Тексты и разметка находятся в `index.html` и `cases.html`.

## Просмотр

Откройте корневой **index.html** двойным щелчком. Либо запустите **OPEN-SITE.cmd**. Node.js, установка зависимостей и локальный сервер для просмотра не нужны. CSS и изображения уже находятся в репозитории.

## Разработка

Требуется Node.js >= 22.12.0. Установка: `npm ci`.

- `index.html` — разметка и контент главной.
- `cases.html` — статическая страница кейсов; открывается двойным щелчком.
- `project-card` в `blocks.scss` — общая карточка для обеих страниц, превью на div.
- `src/styles/blocks.scss` — стили всех блоков, разделённые секциями-комментариями со звёздочками.
- `src/components/` — стили повторяемых элементов.
- [`Modifications/`](Modifications/README.md) — база эффектов: один `modifications.css` и один `modifications.js`, разделённые секциями. Курсор `.go` подключён на карточках кейсов.
- `src/styles/main.scss` — подключение SCSS через `@use`.
- `styles.css` — скомпилированные стили для прямого открытия HTML; хранить в Git вместе с изменениями SCSS.
- `images/` — локальные изображения.
- `fonts/` — локальный NTSomic (400, 500, 600, 700), подключение в `src/styles/fonts.scss`.
- `npm run styles` — обновить CSS после правок SCSS; `npm run styles:watch` — следить за изменениями.
- `npm run dev` — необязательный сервер Vite; `npm run build` — сборка в `dist/`; `npm run preview` — проверка сборки.

После правок SCSS выполнить `npm run styles` или `npm run build` и сохранить обновлённый `styles.css`. `dist/` и `node_modules/` не коммитить.

## Получение обновлений на Windows

В GitHub Desktop нажмите Fetch origin, затем Pull origin, если кнопка появилась. Show in Explorer открывает папку проекта. Для автоматического получения исходников есть `SYNC-FROM-GITHUB.cmd`: только fast-forward из origin/main, без push/reset/stash, с пропуском локальных изменений и коммитов. Закройте его окно для остановки.

Ограничения оригинальных изображений и шрифта: `docs/static-home.md`, `docs/reference-assets.json`. Правила: `AGENTS.md`. Перенос в WordPress — позднее.

Плавный скролл подключён глобально через CDN SmoothScroll 1.4.10 с параметрами пользователя. Требует интернета; без CDN остаётся обычная прокрутка. При reduced motion на загрузке плавный скролл отключён.

Шапка использует модификацию smart-header: фиксируется сверху, скрывается при прокрутке вниз и появляется при прокрутке вверх. Пороги и подключение — в README модификаций.

Страница кейсов восстановлена по https://grammers.pro/cases. Состав, ресурсы и ограничения: `docs/cases.md`.
