# Grammers.pro

Статическая главная по странице `https://grammers.pro/home-page`, восстановленная из предоставленного браузерного архива. Тексты сохранены. Шаблоны Nunjucks и SCSS собираются в обычные HTML и CSS: **в итоговой странице нет JavaScript**.

## Посмотреть без localhost

```sh
npm ci
npm run build
```

Откройте `dist/index.html` двойным щелчком. Пути относительные, все используемые изображения находятся в `dist/images/`; внешние сервисы для отображения страницы не нужны. HTML и CSS можно изучать непосредственно в `dist/`. Сгенерированные файлы не редактировать и не коммитить.

Для разработки: `npm run dev`. Для проверки сборки через HTTP: `npm run preview`. Требуется Node.js >= 22.12.0.

## Где править

- `src/pages/home.njk` — порядок секций главной.
- `src/layouts/base.njk` — каркас документа, метаданные и подключение CSS.
- `src/blocks/<name>/<name>.njk` и `<name>.scss` — разметка и стили конкретного блока.
- `src/components/` — кнопка, заголовок секции, вывод исходных переносов строк.
- `src/data/home.json` — тексты и контент; используется только при сборке, не попадает в браузер как JS.
- `src/styles/main.scss` — явное подключение стилей блоков через `@use`.
- `src/styles/{tokens,base,layout}.scss` — общие настройки, базовая типографика и контейнер.
- `public/images/` — локальные ресурсы страницы.
- `docs/static-home.md` — особенности восстановления, проверки и ограничения ресурсов.
- `docs/reference-assets.json` — соответствие локальных файлов адресам оригинальных изображений.
- `docs/architecture.md`, `AGENTS.md` — архитектура и правила дальнейшей разработки.

jQuery остаётся в зависимостях для последующих этапов. Текущая главная его не подключает. GSAP, плавный скролл, обработка формы и всплывающие окна сейчас не реализуются.
