# База модификаций

Модификация — отдельный эффект, оформленный как самодостаточный кусок CSS, JavaScript или их сочетание. Все CSS и JS модификаций хранятся в этой папке. Базовые стили сайта остаются в `src/`.

## Организация

Один эффект — одно понятное имя файлов: `<effect>.css` и/или `<effect>.js`. Создавать только необходимые файлы. Здесь хранится обычный CSS, пригодный для подключения без компиляции SCSS.

Все комментарии в коде писать на русском языке. В начале каждого файла комментарием указывать название эффекта, необходимую HTML-разметку (классы или data-атрибуты), способ подключения и запуска, настройки и внешние зависимости, если они есть. Модификация должна переноситься без скрытых зависимостей от конкретной страницы или блока сайта.

Если эффект использует CSS и JS вместе, каждый файл должен ссылаться на второй комментарием. Например:

```css
/* Модификация: example. Связанный JS: ./example.js */
```

```js
/* Модификация: example. Связанный CSS: ./example.css */
```

CSS ограничивать классом или атрибутом модификации, JS — её экземплярами. Для нескольких элементов обеспечивать независимую работу и безопасную повторную инициализацию. Указывать необходимость очистки обработчиков и наблюдателей. Для анимаций учитывать `prefers-reduced-motion`; сохранять доступность контента и управление с клавиатуры.

## Порядок работы

1. Сформулировать эффект и условия его применения.
2. Создать необходимые CSS/JS в этой папке и описать подключение комментариями.
3. Проверить эффект отдельно и при использовании на странице; для визуальных эффектов — мобильную и широкую ширину.
4. Добавить в каталог ниже имя, назначение и ссылки на файлы.
5. Подключать к конкретной странице по задаче пользователя. Наличие файла в базе само по себе не включает эффект на сайте.

## Подключение go-cursor

В HTML страницы подключить файлы (пути ниже — от корня проекта):

```html
<link rel="stylesheet" href="./Модификации/go-cursor.css">
<script defer src="./Модификации/go-cursor.js"></script>
```

Добавить `class="go"` любому нужному элементу. Если у него уже есть классы — дописать `go` в тот же атрибут. Вложенные `.go` поддерживаются: работает ближайший к указателю элемент. Новые элементы подхватываются автоматически.

```html
<a class="button go" href="#contact">Обсудить проект</a>
```

Настройки задаются CSS-переменными на элементе:

```css
/* Размер и цвет круга для конкретного элемента. */
.custom.go {
  --go-cursor-size: 100px;
  --go-cursor-color: #fd7d2f;
  --go-cursor-blend: normal;
  --go-cursor-opacity: 0.7;
}
```

По умолчанию: 80 px, белый круг с режимом наложения `difference`. Системный указатель сохраняется. Круг появляется только внутри `.go`, обрезается по прямоугольнику элемента и его скруглениям, не перехватывает клики. Для повёрнутых элементов, нестандартных clip-path и многострочных inline-элементов понадобится отдельная маска; текущая область — bounding rectangle.

Ориентир физики — [курсор Cuberto](https://cuberto.com/): сглаженное следование и растяжение по направлению скорости. Реализация написана отдельно на нативном JS, без копирования библиотеки MouseFollower и без GSAP. Настройки по времени и максимальному растяжению находятся в JS. При reduced motion следование мгновенное, без деформации; сенсорные касания эффект не включают.

Управление: `window.GoCursor.destroy()` снимает обработчики и удаляет слой; `window.GoCursor.init()` запускает заново. Повторный запуск безопасен. В главную модификация пока не подключена. Демо можно открыть двойным щелчком по `go-cursor-demo.html`.
