# База модификаций

Модификация — отдельный эффект, оформленный как самодостаточный кусок CSS, JavaScript или их сочетание. Все CSS и JS модификаций хранятся в этой папке. Базовые стили сайта остаются в `src/`.

## Организация

Один эффект — одно понятное имя файлов: `<effect>.css` и/или `<effect>.js`. Создавать только необходимые файлы. Здесь хранится обычный CSS, пригодный для подключения без компиляции SCSS.

В начале каждого файла комментарием указывать название эффекта, необходимую HTML-разметку (классы или data-атрибуты), способ подключения и запуска, настройки и внешние зависимости, если они есть. Модификация должна переноситься без скрытых зависимостей от конкретной страницы или блока сайта.

Если эффект использует CSS и JS вместе, каждый файл должен ссылаться на второй комментарием. Например:

```css
/* Модификация: example. Связанный JS: ./example.js */
```

```js
/* Модификация: example. Связанный CSS: ./example.css */
```

CSS ограничивать классом или атрибутом модификации, JS — её экземплярами. Для нескольких элементов обеспечивать независимую работу и безопасную повторную инициализацию. Указывать необходимость очистки обработчиков и наблюдателей. Для анимаций учитывать `prefers-reduced-motion`; сохранять доступность контента и управление с клавиатуры.

## Порядок работы

1. Сформулировать эффект и условия его применения.
2. Создать необходимые CSS/JS в этой папке и описать подключение комментариями.
3. Проверить эффект отдельно и при использовании на странице; для визуальных эффектов — мобильную и широкую ширину.
4. Добавить в каталог ниже имя, назначение и ссылки на файлы.
5. Подключать к конкретной странице по задаче пользователя. Наличие файла в базе само по себе не включает эффект на сайте.
