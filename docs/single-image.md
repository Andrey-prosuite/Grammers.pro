# Одиночное изображение

Единый блок `single-image` объединяет прежние одиночные иллюстрации, обложку и крупное превью. Геометрия — `Blocks/blocks.scss`. Эффекты остаются в существующих секциях 08 (ImageViewer) и 09 (PhotoParallax) общих CSS/JS; отдельного контроллера и копий анимаций нет.

## Разметка

```html
<figure class="single-image case-section" data-single-image
        data-image-layout="content"
        data-image-zoom="false" data-image-parallax="false">
  <div class="single-image__frame" data-image-frame>
    <img class="single-image__image" src="./images/case/brodeks/brand-story.webp"
         width="1680" height="823" alt="Описание изображения"
         loading="lazy" decoding="async">
  </div>
  <figcaption class="single-image__caption">Необязательная подпись</figcaption>
</figure>
```

Одна figure, один кадр и img/picture. Кадр нужен для ограничения параллакса, скругления и размещения картинки внутри серого фона. Скрипты не создают обёрток. Подпись необязательна, находится снаружи кадра. Сохранять alt, width/height, естественные пропорции. Для первого изображения использовать fetchpriority="high", не loading="lazy". Корень full/inset/surface размещать вне узких колонок и предков с overflow/clip.

## Четыре варианта

| data-image-layout | Геометрия |
| --- | --- |
| content | По колонке контента: min(100% - 2 × --page-gutter, --case-content-width), сейчас максимум 1500px. Это также вариант по умолчанию и при неизвестном значении |
| inset | На ширину экрана с полями --image-gutter, по умолчанию 40px с каждой стороны |
| full | На всю ширину экрана, без боковых полей и максимальной ширины; высота по изображению |
| surface | Серый фон с полями --image-gutter от краёв экрана; внутреннее изображение по центру, максимум --case-content-width (1500px), не шире самого фона |

`full` не навязывает высоту 100vh: естественные пропорции сохраняются. При необходимости высоту кадра можно задать отдельно через --image-height, например 100svh. На узком экране контентный вариант использует общие поля страницы; inset/surface сохраняют заданные 40px, если пользователь не переопределил переменную. Внутренняя картинка поверхности сужается вместе с фоном и не выходит за него.

```html
<figure class="single-image case-section" data-single-image
        data-image-layout="surface" data-image-zoom="true" data-image-parallax="true"
        style="--image-gutter: 40px; --image-radius: 20px;">
  <div class="single-image__frame" data-image-frame>
    <img src="./images/case/brodeks/brand-story.webp" width="1680" height="823"
         alt="Описание изображения" loading="lazy" decoding="async">
  </div>
</figure>
```

## Опции и настройки

| Настройка на figure | По умолчанию | Назначение |
| --- | --- | --- |
| data-image-layout | content | content / inset / full / surface |
| data-image-zoom | false | Только true включает общий зум-просмотрщик |
| data-image-parallax | false | Только true включает существующий параллакс и стандартное появление |
| data-image-appear | auto (при отсутствии) | rise — второе появление: подъём300px, opacity 0→1 за 1s; auto — прежнее поведение |
| --image-gutter | 40px | Поле от края экрана для inset/surface; можно переопределить в inline style или CSS на нужном breakpoint |
| --image-radius | 0px | Скругление кадра |
| --image-ratio | auto | Пропорция кадра; при auto изображение определяет высоту |
| --image-height | auto, запасное значение | Явная высота кадра, если нужна обрезка с object-fit:cover |
| --image-surface-color | #e8e8e8 | Цвет серой поверхности |
| --image-surface-padding | 8vw | Верхнее/нижнее внутреннее поле поверхности, сохранённое из прежнего блока |
| data-image-title на кадре | alt изображения | Необязательная подпись в просмотрщике |

Опции zoom/parallax независимы и сочетаются с любым из четырёх вариантов. data-image-appear="rise" работает с параллаксом или без него и заменяет стандартное появление кадра. При отсутствии/неизвестном значении сохраняется auto: прежнее появление у включённого параллакса, обычная картинка без появления при выключенном параллаксе. Не добавлять классы photo-zoom/photo-parallax вручную к кадру: общий код распознаёт data-* блока. Увеличение создаёт доступную кнопку из существующего кадра, с Tab/Enter/Space и возвратом фокуса; без JS остаётся обычная картинка. Текущая обычная картинка — полный ресурс просмотрщика (currentSrc/src). Прежние ссылки photo-zoom вне single-image продолжают работать.

## Параметры эффектов сохранены

Параллакс: scale 1.05, yPercent -10→10, start top bottom, end bottom top, scrub true, ease none. Запас медиа 125% по высоте, top -12.5% закрывает края. Если кадр виден при инициализации: clip-path inset(5% 10%)→0 и scale .9→1 за 2.5s expo.out с задержкой .1s, opacity за 1s. Для кадров ниже экрана — прежнее появление opacity за 1s при входе в область просмотра. Исходная картинка доступна при ошибке JS/отсутствии GSAP; reduced motion откатывает движение и появление.

Увеличение использует существующий ImageViewer: затемнение, кнопка «Крупнее», Esc/закрытие/возврат фокуса, мобильное увеличение 200% с панорамированием. Параметры просмотрщика не менялись. Он работает без GSAP.

Дополнительное появление rise: кадр перемещается из y=300px в y=0, opacity 0→1, duration1s, ease power1.out, без задержки. Запуск один раз при входе внешней figure в область экрана (top 85%); при первоначальной видимости начинается после инициализации. Анимируется существующий кадр, серый фон неподвижен. Эффект отключается при reduced motion, без JS картинка видима.

## Подключение и очистка

Общие CSS/JS и локальные GSAP/ScrollTrigger уже подключены на трёх страницах. Нет отдельной SingleImage.init(): блок использует ImageViewer.init/destroy и PhotoParallax.init/destroy. При добавлении/удалении блоков либо изменении zoom/parallax/appear на открытой странице сначала destroy обоих модулей, затем init. Изменение только layout/переменных обрабатывает CSS, существующий ResizeObserver обновляет параллакс. Очистка возвращает стили, атрибуты кадра, фокус, наблюдатели и анимации; повторная инициализация безопасна. Служебный data-photo-parallax-ready не сохранять в HTML.

В WordPress выводить один шаблон figure/frame/image с полями layout, zoom, parallax, gutter и опциональными размерами/цветами. Подключать общие эффекты через enqueue один раз; картинки, alt и размеры — через API WordPress, с экранированием. Не выводить ссылку/пустые якоря, если она нужна только для необязательного зума.

## Текущие экземпляры

Все одиночные case-media и case-cover переведены на single-image, старые стили удалены. Обычные иллюстрации — content без эффектов, серые панели — surface без эффектов. У #case-usability-image после «Путь клиента и Usability сайта» параллакс по последнему указанию выключен, серый фон сохранён, zoom false; для теста включено data-image-appear="rise". Обложка после H1 — inset с --image-gutter:40px, zoom/parallax true; сохранены скругление 20px и высоты 672/405/342px по прежним breakpoint. Прежнее крупное превью (#case-parallax-preview) — content, обе опции true, пропорции 16:9 на desktop и 355:400 до 767px. case-pair/pages/columns, галереи, многокартиночная композиция case-details и карточки case-split остаются самостоятельными блоками.

При добавлении нового блока уточнять недостающие настройки одним вопросом: изображение, вариант ширины/фона, поле для inset/surface, увеличение, параллакс, вариант появления, скругление и необходимость фиксированной высоты. Уже согласованные параметры не переспрашивать. Инструкции обновлять автоматически вместе с кодом.

## Место в библиотеке

Каноническая разметка: [Blocks/templates/single-image.html](../Blocks/templates/single-image.html); [инструкция агентам](../Blocks/AGENTS.md), [визуальный каталог](../Blocks/index.html#single-image). Базовый CSS собирается в Blocks/blocks.css отдельно от styles.css. Собственного контроллера нет: zoom/parallax/appear подключают существующие модификации, не копируются в blocks.js. Контентные изображения остаются в общей images/.

При новой установке применять [методику компонентов и экземпляров](../Blocks/METHODOLOGY.md): сначала выбрать источник (существующий экземпляр или исходный компонент), затем создать независимый экземпляр с уникальными именами/классами и кодом страницы. Текущие ранние установки этого блока пока относятся к явно описанному переходному состоянию.
