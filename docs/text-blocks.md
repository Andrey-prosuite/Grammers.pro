## Подключение и установка

Каталог использует общие styles.css, Blocks/blocks.css и Modifications/modifications.css. Стили компонентов — секции04–06 Blocks/blocks.scss, результат Blocks/blocks.css. Blocks/blocks.js содержит указание на общую модификацию, пустых контроллеров нет.

Новая установка — независимая копия: переименовать корень и все __элементы, перенести соответствующие правила в SCSS страницы, заменить ID и aria-labelledby. Сохранить общие data-метки эффекта; код TextReveal в страницу не копировать. Прежде уточнить компонент или существующий экземпляр, если пользователь ещё не выбрал источник.

## Необязательные части

Заголовок, описание, вводный абзац, список и отдельные пункты удаляются целиком, без пустых заглушек. Единственный оставшийся прямой ребёнок section занимает всю сетку. Без вводного абзаца список начинает колонку сразу; gap не создаёт пустое место. Если список удалён, оставить только нужный абзац в __body. При удалении заголовка убрать aria-labelledby и дать section содержательный aria-label; не оставлять ссылку на отсутствующий ID. Если содержимого совсем нет, убрать весь section.

Для нескольких абзацев в summary помещать p в __body; они появляются вместе. В tasks/feature несколько отдельных абзацев можно явно пометить data-text-reveal-item. Один H1 остаётся у страницы, заголовки экземпляров — H2 либо соответствующий контексту уровень.

## Появление: TextReveal

Общая модификация14 в Modifications/modifications.js, без собственного скрывающего CSS. На section — data-text-reveal, на нужном описании/абзаце/li — data-text-reveal-item. Заголовки в шаблонах статичны. data-text-reveal="false" выключает эффект; удаление меток целей оставляет соответствующую часть статичной.

Зависимости: локальные GSAP и ScrollTrigger перед общим JS модификаций с defer. Прозрачность0→1 за3s, cubic-bezier(.19,1,.22,1), без перемещения; один раз, когда верх каждой цели входит снизу в экран (top bottom). Пункты получают задержку по текущему порядку0/.1/.2…s, обычные описания —0. data-text-reveal-delay="0.2" явно заменяет задержку в секундах; отрицательное/нечисловое значение возвращает автоматическое. Длительность, кривая, порог и отсутствие перемещения — константы, публичных опций для них нет.

Эффект ждёт page-transition:ready, если шторка ещё закрывает страницу. Вложенные корни обрабатывают только собственные цели. TextReveal.init()/destroy() повторно безопасны; после динамической замены контента выполнить destroy/init. Destroy удаляет ожидание событий, откатывает matchMedia/анимации/ScrollTrigger и восстанавливает исходные opacity/visibility. После завершения fade временные свойства также восстанавливаются. Не назначать одновременно другой эффект на opacity тех же целей; параллакс соседних изображений совместим.

Reduced motion, отсутствие JS/GSAP/ScrollTrigger или ошибка создания эффекта оставляют текст доступным. Контент всегда присутствует в обычном HTML и доступен поиску; не ставить hidden или opacity0 в исходную разметку.
