# Кейс Brodeks

Страница: `case.html`. Референс пользователя: https://grammers.pro/brodeks, изучен 20 октября 2026 года. HTML, видимый DOM и опубликованный https://grammers.pro/custom.css были доступны напрямую. Проверены широкая версия и мобильный вариант после перезагрузки, поскольку Zero Block не сразу пересчитывает геометрию при смене ширины.

## Контент и ресурсы

Сохранены видимые тексты Brodeks: вступление, задачи, показатели, описание бренда и сведения о проекте, начало и ход работ, SEO, доработка концепции, визуальное решение, узнаваемость, детали, Usability, программная реализация, мобильная версия, результат, достижения и приглашение к проекту. Тексты остаются в HTML, а не на изображении страницы.

В исходном `rec793229375` за пределами обрезанного блока находятся тексты BigSmartTeam, Telegram-бота и отзыв о другом разработчике. В видимой области этого блока находится только приглашение «Хотите такой же проект?». Обрезанные чужие материалы не перенесены.

Оригинальные изображения скачаны с `static.tildacdn.com`, сохранены в `images/case/brodeks`. PNG и JPEG переведены в WebP quality 94 без увеличения исходных размеров; исходная WebP-обложка сохранена без повторного сжатия. Размеры и ссылки на каждый ресурс — в `brodeks-assets.json`. SVG стрелок взяты из оригинального блока галереи; служебные ID и повторные XML-комментарии удалены. Прежний тестовый длинный скриншот в карточках главной и списка кейсов не менялся.

По отдельному уточнению пользователя видео `https://video.grammers.pro/2.mp4` сохранено локально как `overview.mp4` (около 4,3 МБ). Используются autoplay, muted, loop, playsinline; добавлены нативные controls для паузы и ручного запуска. Обложка — кадр оригинального видео. Секция 06 общего JS отключает автозапуск при reduced motion и приостанавливает видео в скрытой вкладке; ручная пауза сохраняется при возвращении во вкладку. Зависимостей нет.

## Вёрстка

- Компактная статья с одним H1, последовательными H2, списками, dl, figure, img с alt и размерами. Хлебные крошки — nav и ol; последний пункт имеет aria-current.
- Заголовок 70px/70px, описание 42px/48px, скругление обложки 20px, её высота 672px на desktop. На мобильном заголовок 36px, описание 28px/32px, высота обложки 342px до 479px и 405px до 959px — по оригиналу.
- Основные текстовые секции: заголовок 36px и текст 18px/28px; мобильные 28px и 15px/23px. До 959px текстовые колонки перестраиваются в одну. Отступы секций обычно 120px, на телефонах 60px, с явными вариантами для блоков оригинала.
- Серые поверхности крупных макетов: #e8e8e8, поля 8vw по вертикали и 5vw по горизонтали — из `.uc-caseimage_1280` оригинального custom.css. Внешние поля 20px, до 479px поверхность занимает всю ширину.
- Текстовые блоки собраны на Grid и в потоке документа. Абсолютное размещение применяется только к составной композиции изображений каталога и тексту поверх фотографии бренда.
- Общая шапка получила явный вариант site-header-case. Одна навигация используется на всех ширинах; на мобильном открывается нативным details без JS. Подвал общий с существующими страницами.
- Галереи прототипов и телефонов — нативные горизонтальные ленты с CSS scroll-snap. Стрелки ведут к первому и последнему кадру, промежуточные доступны прокруткой. Дипломы выбираются якорными миниатюрами. Это статическая реализация текущего этапа: пошаговый JS-слайдер Тильды и анимации появления не переносились. Позднее по новому запросу добавлены независимые сетки и общий просмотр изображений  — см. `case-blocks.md`.

Все блоки case-* находятся отдельными секциями в `src/styles/blocks.scss`, CSS собран в `styles.css`. Нет разметки Zero Block, библиотек Тильды, аналитики, cookie-баннера и сторонних виджетов. Общий согласованный SmoothScroll с CDN сохранён. Vite собирает все три страницы с относительными путями. Корневую `case.html` можно открыть двойным щелчком.

## SEO и перенос

Сохранён исходный title «Как мы трансформировали бренд спецодежды в категорию экипировки для профессионалов» и canonical `/brodeks`. Добавлены description и Open Graph. Адрес og:image соответствует расположению локальной обложки при публикации файлов в корне сайта; при переносе в WordPress заменить через API медиа.

Ссылки карточек главной и списка кейсов пока ведут на исходные опубликованные кейсы. Автоматического переключения на локальную страницу не делалось. Контент, медиаресурсы и варианты оформления можно перенести в поля WordPress; Gutenberg/ACF ещё не выбраны.

Контент кейса имеет общий верхний предел `--case-content-width: 1500px` (tokens.scss). Более узкие размеры блоков сохранены. У серых поверхностей case-media-framed/case-video/case-details ширина фона сохраняется, ограничивается внутреннее изображение или вся композиция через case-details__composition. Галереи и строка ограничены по видимому окну, их прокручиваемое содержимое остаётся длинным.
