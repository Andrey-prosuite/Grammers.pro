# Модификации фотографий

Эффекты включаются независимо на выбранных фотографиях, на любой странице. Классы секций и кейсов не нужны. Общие CSS/JS, локальные GSAP и ScrollTrigger уже подключены во всех трёх HTML-страницах.

## Параллакс — photo-parallax

Добавить класс к существующему контейнеру изображения. Поддерживаются прямой img, picture с img и video. Контейнер содержит только медиа; подпись размещается снаружи. Новые обёртки скрипт не создаёт.

```html
<figure>
  <div class="photo-parallax">
    <img src="./images/photo.webp" width="1600" height="1000" alt="Описание фотографии" loading="lazy" decoding="async">
  </div>
  <figcaption>Подпись фотографии</figcaption>
</figure>
```

Размер, радиус и при необходимости aspect-ratio кадра задаёт сам блок. Если пропорции кадра не заданы, модификация сохраняет исходное соотношение его ширины и высоты; width/height изображения резервируют место до загрузки. В активном состоянии медиа получает высоту 125% и top -12.5%: запас закрывает края при движении. object-fit: cover сохраняет пропорции изображения. Без JS и при reduced motion остаётся обычная фотография.

Параметры движения прежние: scale 1.05, yPercent -10→10, start `top bottom`, end `bottom top`, scrub true, ease none. Обычное появление — opacity за 1s. Необязательный data-parallax-reveal сохраняет исходное раскрытие для кадра, уже видимого при инициализации. Если путь должен включать подпись, добавить data-parallax-trigger на внешнюю figure. Старые data-case-parallax и data-parallax-media поддерживаются для совместимости.

PhotoParallax.init() повторно безопасен. После добавления/удаления фотографий вызвать PhotoParallax.destroy(), затем PhotoParallax.init(). Очистка убирает наблюдателей и анимации, возвращает исходные стили и служебные атрибуты; переключение reduced motion откатывает эффект. CaseParallax — совместимый псевдоним того же API.

## Увеличение по клику — photo-zoom

Добавить класс на обычную ссылку с img или picture. href указывает на полное изображение; alt и width/height остаются на img. Без JS ссылка открывает файл.

```html
<a class="photo-zoom" href="./images/photo-full.webp">
  <img src="./images/photo-preview.webp" width="800" height="500" alt="Описание фотографии">
</a>
```

Клик открывает общий просмотрщик с затемнением и кнопкой «Крупнее». Esc, кнопка закрытия, фон или короткий клик по листу закрывают его; фокус возвращается на исходную ссылку. На телефоне увеличение до 200% с панорамированием. Необязательный data-image-title меняет подпись. Ctrl/Cmd-клик сохраняет обычное поведение ссылки. Без этого класса просмотрщик фотографию не перехватывает.

Также поддерживается button.photo-zoom с img (источник из currentSrc) и прежний data-image-viewer. Для динамических ссылок перезапуск не требуется: используется делегирование. API ImageViewer.init()/destroy()/open()/close() сохранён. Vite обрабатывает локальные href для обоих способов подключения.

## Оба эффекта

```html
<a class="photo-parallax photo-zoom" href="./images/photo.webp">
  <img src="./images/photo.webp" width="1600" height="1000" alt="Описание фотографии">
</a>
```

Убрать любой из классов — отключить соответствующую возможность в разметке. Существующие выбранные фотографии кейса используют эти классы. Остальные изображения автоматически не подключаются.

Реализация: секции 08 и 09 Modifications/modifications.css и modifications.js. В WordPress добавлять классы условно по выбору редактора, href/alt/размеры выводить через API WordPress и экранировать; модификации подключать один раз через enqueue. GSAP и ScrollTrigger нужны только для параллакса, просмотрщик от них не зависит. Источники параметров — case-motion-blocks.md и case-blocks.md.

Для одиночного изображения использовать [single-image.md](single-image.md): единый блок с четырьмя layout и независимыми data-image-zoom/parallax. Он вызывает те же эффекты секций 08/09 напрямую по data-меткам, дублировать классы на его кадре не нужно. Классы photo-parallax/photo-zoom остаются для других выбранных фотографий и составных блоков.

Второй эффект появления single-image: data-image-appear="rise" — y 300px→0, opacity 0→1, 3s power1.out, один раз, когда верх figure достигает 85% высоты экрана. Работает независимо от data-image-parallax и заменяет стандартное появление; отсутствие атрибута (auto) сохраняет прежнее поведение. Использует существующий PhotoParallax секции 09, без нового контроллера/обёрток, reduced motion и очистка сохранены. Тестовый блок #case-usability-image: surface, zoom false, parallax false, appear rise. При запросе нового одиночного изображения уточнять и вариант появления, если он не указан.

Текущее размещение базовых single-image/horizontal-gallery: библиотека [Blocks](../Blocks/README.md), её [инструкции](../Blocks/AGENTS.md). Собственный контроллер галереи перенесён в Blocks/blocks.js, стили — Blocks/blocks.scss → Blocks/blocks.css. Эффекты ImageViewer/PhotoParallax/ScrollReel остаются в Modifications и подключаются к блокам.
