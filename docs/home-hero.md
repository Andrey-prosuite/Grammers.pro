# Хиро главной — hero-home

Индивидуальный экземпляр уже установленного хиро главной. Разметка — index.html, стили — первая секция src/styles/pages/home.scss, подключение через main.scss → styles.css. Старые неиспользуемые .hero/.hero__* удалены из src/styles/blocks.scss. Это не новый компонент библиотеки; при переносе в новое место применять методику компонент/экземпляр и сначала уточнить источник.

## Разметка и контент

Одна section.hero-home с aria-labelledby="hero-home-title"; единственный H1 страницы .hero-home__title; описание .hero-home__description; одна ссылка .hero-home__announcement на case.html; блок награды .hero-home__award с figure/figcaption и подписью. Не дублировать ссылку ради иконки. Текст описания обновлён на согласованное оформление: «Делаем сайты для производителей и брендов. b2b и b2c». Кнопки внутри этого хиро нет; контактная кнопка шапки сохраняется.

Контентные ресурсы:

- images/home/brodeks-announcement.png — исходное изображение 1622×1005, показ в кадре447:271 через object-fit:cover; скругление34px на базовой ширине.
- images/home/project-arrow.svg — готовый знак перехода с нативным размером60.9185×60.9185, декоративный img. SVG не редактируется; на меньших экранах масштабируется transform.
- images/awards/developer.svg — существующий совпадающий знак награды, 63×54, вывод73×62.57 на базовой ширине; не заменять многослойной разметкой.

Все ресурсы локальны; временных сетевых адресов в HTML/CSS нет. Изображение кейса имеет width/height, fetchpriority=high и decoding=async. Подпись ссылки доступна, иконка декоративная, клавиатурный фокус виден. Обычный переход работает без JS; локальный файл case.html существует. Остальные карточки кейсов и их адреса не переназначены.

## Геометрия и адаптивность

Базовая композиция1920×773: заголовок110px/99px, насыщенность500 и трекинг−6px, максимальная ширина865.42px; описание42px/1.15, ширина570.65px. Левая граница заголовка127.05px; верх62px. Карточка447×271 с верхом53px и правым полем82px. Награда под карточкой, описание под заголовком. Сетка Grid и Flex в обычном потоке; абсолютные элементы только внутри карточки для текста, градиента и иконки.

До1920px размеры плавно уменьшаются через внутреннюю --hero-home-unit: min(1px, .0520833333vw). Выше1920 композиция сохраняет максимальные размеры и центрируется, фон страницы виден до краёв экрана. Фон секции — --hero-home-background: transparent; общий белый фон страницы не меняется. Это локальные CSS-переменные экземпляра, не inline data-опции или настройки JS.

До959px: заголовок занимает всю строку, под ним описание/награда слева и карточка справа; шрифты имеют отдельные читаемые размеры. До639px: одна колонка в порядке заголовок → описание → карточка → награда, поля страницы20px, карточка максимум447px. На320px длинная первая строка H1 естественно переносится. Шапка и остальные секции не входят в редизайн.

## Поведение, зависимости и очистка

Собственного JS и скрывающей модификации нет. Анонс: CSS-сжатие фрейма до scale(.95) за .75s cubic-bezier(.16,.44,0,.97) при hover точного указателя и видимом клавиатурном фокусе. Изображение с градиентом находится в hero-home__announcement-frame; подпись и круг — соседние элементы вне трансформируемого фрейма, их координаты сохраняются. Reduced motion убирает переход, фрейм переключается сразу. Достаточно локального NTSomic, общих токенов и styles.css. Глобальная шторка страницы действует обычным способом; не добавлять второй эффект появления на H1 без запроса. Нет контроллера для init/destroy и нет слушателей для очистки. У анонса одна необходимая обёртка фрейма, чтобы сжатие не двигало подпись и круг. Контент всегда доступен без JS и при reduced motion. Редактировать только экземпляр; не вводить общий селектор h1 для его оформления.

Для WordPress сохранить DOM/классы, заменить текст, ссылку и медиа полями; изображения хранятся в общей медиатеке. Предварительный PHP в статический проект не добавлять.

Проверки: компиляция SCSS, production-сборка; геометрия и локальные изображения в браузере на320/390/768/1024/1440/1920px. У элементов хиро нет горизонтального переполнения. Чужие секции/шапка проверяются только на отсутствие регрессии от нового экземпляра.

Актуальные базовые отступы анонса: caption bottom35.65 и left34.7, arrow top14.83 и right17.13, каждый через calc(значение * --hero-home-unit). До959px у подписи остаются адаптивные bottom/left20px. Сжатие фрейма не меняет эти координаты.
