# Статическая главная: восстановление оригинала

## Источник и тексты

Источник — предоставленный пользователем архив сохранённой страницы «Главная by Andrey» с `https://grammers.pro/home-page`. HTML и SCSS написаны заново; код Тильды не переносится. Тексты секций извлечены из исходного HTML, включая исходные опечатки, и сохранены в `index.html`. Значимые ручные переносы строк сохранены элементами `<br>`.

Сохранены структура и визуальные приёмы оригинала: крупная типографика, асимметричные сетки, оранжевые и тёмные карточки, кейсы, награды, форма и тёмный подвал. Для адаптива используется нормальный поток, CSS Grid и Flexbox. Масштабирование и абсолютные координаты Zero Block не используются. Абсолютное позиционирование оставлено только для декоративного наложения телефона на превью проекта и служебной ссылки перехода к контенту.

## Ограничение исходных ресурсов

Пользователь предоставил NTSomic в WOFF2. Локальные файлы находятся в `fonts/`: Regular 400, Medium 500, Semibold 600, Bold 700; подключены через `src/styles/fonts.scss` с `font-display: swap`. Arial остаётся запасным шрифтом. Точное визуальное совпадение с живой страницей ещё не подтверждено.

Восемь растровых файлов сохранены браузером как маленькие lazy-loading-превью, а не оригиналы:

- Шесть изображений кейсов: 20×16 px.
- Фото менеджера: 20×20 px.
- Длинный скриншот AG-Technologies: миниатюра; точный размер в `reference-assets.json`.

Они перенесены без искусственного увеличения детализации. Логотипы, платформы и награды из SVG/PNG доступны локально. Адреса оригиналов и размеры всех файлов записаны в `reference-assets.json`. Для финальной визуальной сверки нужны полноразмерные версии этих восьми файлов. Сохранять те же локальные пути при замене изображений. Локальный шрифт уже подключён через `@font-face`.

Адреса шрифтов из оригинального CSS:

- `https://static.tildacdn.com/tild3931-3365-4139-a464-333262623133/NTSomic-Regular.woff`
- `https://static.tildacdn.com/tild3730-6639-4236-b432-643633613564/NTSomic-Medium.woff`
- `https://static.tildacdn.com/tild3137-3666-4565-a633-636132353330/NTSomic-Bold.woff`

Страница не загружает внешние ресурсы для отображения. Указанные URL — справочная информация для получения оригиналов.

## Что сознательно исключено на этом этапе

- Весь JS Тильды, аналитика, трекеры, коллтрекинг, виджеты чата и личного кабинета.
- Скрипты проекта, jQuery, GSAP, анимации, hover-эффекты, плавная прокрутка, карусельные дубликаты и стили с inline-координатами.
- Невидимая дублирующая подпись «Подход» и служебные элементы платформы.

Логотипы клиентов и награды доступны в горизонтальных областях с обычной ручной прокруткой, включая клавиатуру. Навигация на узком экране показана строкой ссылок, без JS-бургера. Кнопки брифа ведут к форме на этой странице. Ссылки на существующие кейсы и другие страницы ведут на действующий сайт. Направления работы ведут к обсуждению проекта, поскольку отдельные лендинги ещё не сверстаны.

Поля формы — статический образец. Отправка отключена через disabled submit, обработчик и endpoint не подключены. Кнопка «Макс» отключена: в сохранённом оригинале у неё не было ссылки. «Телеграм» направлен на существующий контакт студии; в архиве соответствующая кнопка ошибочно указывала на SVG-файл.

## Проверка

- `npm run build` — итог содержит HTML и один CSS-файл, без JS.
- `npm exec --yes --package html-validate -- html-validate dist/index.html` — проверка семантики HTML.
- Проверка в Chromium с отключённым JS на ширинах 320, 390, 768, 1024, 1440 и 1920 px: изображения загружаются, секции помещаются в экран.
- Сверка текстовых фрагментов исходных секций с собранным HTML, проверка уникальности ID и существования целей якорей.

Размеры и количество DOM-элементов измеряются по собранному `dist/index.html`, а не по исходному HTML. Оптимизация разметки не заменяет дальнейшую оптимизацию полноразмерных изображений после их получения.
