# Новый кейс Brodeks

`brodeks.html` — отдельная страница с новой редакцией текстов кейса и пустыми серыми кадрами. `case.html` остаётся прежней страницей с оригинальными материалами и примерами блоков. Новая страница входит в Vite-сборку и открывается двойным щелчком; в разработке — http://127.0.0.1:4181/brodeks.html. Ссылки карточек автоматически не переключались.

## Источник и состав

По указанию пользователя использованы последние текстовые экземпляры из `case.html`, описанные в [text-blocks.md](text-blocks.md). Новые копии независимы; исходные компоненты библиотеки не менялись. Разметка — `brodeks.html`, SCSS — `src/styles/pages/brodeks-story.scss` → общий `styles.css`.

| Экземпляр | Источник | Состав |
| --- | --- | --- |
| text-summary-brodeks-story | text-summary-brodeks | Клиент, крупное описание справа |
| text-tasks-brodeks-story-tasks | text-tasks-brodeks | Вводный абзац, четыре последовательных пункта задач |
| text-tasks-brodeks-story-results | text-tasks-brodeks | Четыре показателя из итогового раздела кейса |
| text-feature-brodeks-story-{место} | text-feature-brodeks | Крупный заголовок слева, короткий абзац справа; список удалён |

Места feature: prototypes, seo, visual, brand, details, purchase, selection, development, mobile, result, awards, contact. У каждого собственные классы корня/элементов, ID и aria-labelledby. В contact дополнительно обычная ссылка на форму главной. Приватные SCSS-заготовки `%text-tasks-brodeks-story` и `%text-feature-brodeks-story` объединяют одинаковые правила только этой страницы; это не публичные компоненты и не зависимость от старых CSS-селекторов.

Тексты взяты из предшествующего обсуждения: производитель спецодежды, B2B и розница, SEO, визуальная концепция, бренд, качество изделий, сценарии заказа, размеры/сравнение, интеграции, мобильная версия, результаты и награды. Метаданные описывают интернет-магазин спецодежды; canonical сохраняет опубликованный адрес `/brodeks`.

Числа предварительно перенесены из итогового раздела исходного кейса: скорость загрузки +35%, глубина +51%, время +18%, конверсия добавления в корзину +24%. До публикации уточнить период сравнения и расхождение с показателями в начале оригинала. Не подменять конверсию добавления в корзину конверсией в покупку.

## Геометрия и пустые кадры

Текстовые блоки сохраняют геометрию выбранных экземпляров: максимум1500px, поля40px /20px до959px; feature44px, до639px32px. До1023px одна колонка. Состав и высота определяются текстом. Параметры --text-content-width, --text-space-before/after, --text-column-gap унаследованы из выбранных экземпляров с теми же значениями по умолчанию; полный справочник — text-blocks.md.

Вступление — индивидуальный brodeks-story-hero, не библиотечный компонент. Один H1; крошки, год2024, ссылка на сайт бренда и вводный абзац.

Медиа — brodeks-story-media с пустыми __frame, цвет #e8e8e8. Нет картинок, видео, подписей, ссылок или обработчиков. Контейнер aria-hidden=true исключает декоративные заготовки из доступного дерева. Русские HTML-комментарии и ID обозначают назначение будущих изображений.

Варианты кадров — фиксированные классы, не публичные data-настройки:

- cover: вся доступная ширина с внешними полями,16:8; до639px4:3.
- wide: по контентной колонке,16:9.
- pair: два кадра4:3, промежуток20px; до639px одна колонка, промежуток16px.
- phones: четыре кадра9:18; до639px две колонки.

Радиус20px, до639px12px. При замене заготовок настоящими медиа убрать aria-hidden, добавить содержательные alt и размеры, заново явно выбрать просмотр/параллакс; пустые кадры не инициализируют эффекты фотографий.

## Эффекты, зависимости и очистка

Общий TextReveal14 подключён data-text-reveal / data-text-reveal-item; заголовки статичны, описание и пункты появляются по прежним параметрам. Код эффекта не скопирован. GSAP/ScrollTrigger локальные, SmoothScroll1.4.10 с прежним SRI; порядок общего head сохранён. Единая шторка подключена одним page-transition.js до CSS. Без JS/reduced motion весь текст остаётся доступен. Очистка TextReveal.init/destroy и PageTransition.init/destroy — общие API.

Cookie скопирована из установленной cookie-notice-brodeks: отдельные классы/data-cookie-notice-brodeks-story и BrodeksStoryCookieNotice.init/destroy/show(id), JS `src/scripts/pages/brodeks-story.js`. Подтверждение общее для сайта365дней, настройки появления900/600ms и адаптив сохранены. Новый и старый контроллеры не выбирают чужие корни. Общие шапка/подвал сохранены как инфраструктура сайта.

Страница подключает общий набор CSS/JS с версией20261021-brodeks-story-1. Vite копирует обычный JS страницы и сохраняет работу file://. Собственного JS у текстов, вступления и кадров нет. В WordPress перенести текст и медиа в поля, общие подключения — в тему; модель полей пока не выбрана.
