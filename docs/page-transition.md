# Глобальная шторка страниц

Одно подключение в `<head>` **до CSS**, без `defer` и `async`:

```html
<script src="./Modifications/page-transition.js?v=20261020-global-curtain-1"></script>
```

Это весь код подключения. Файл содержит раннюю маску, CSS и контроллер. На `body` ничего добавлять не нужно; список страниц, корень каталога и sessionStorage больше не используются. В подпапке поправить относительный путь (`../Modifications/page-transition.js`). В статическом сайте строка нужна в head каждой страницы; в WordPress её размещают один раз в общей шапке/общем подключении темы для всех страниц, обязательно до отображения контента.

Эффект включён на главной, списке кейсов, кейсе и в библиотеке. При прямом входе, обновлении и новой вкладке выполняется открытие; при внутреннем переходе — сначала закрытие текущего документа, затем открытие нового. [Рабочая выборка](../Blocks/index.html#page-curtain) показывает тот же механизм без навигации.

## Последовательность

| Этап | Движение | Длительность и кривая |
| --- | --- | --- |
| Уход | Два слоя растут сверху от height0 до100%; верхний графит#1a1a1a, под ним белый#fff | 700ms, power3.inOut |
| Уход контента | main сдвигается вниз20vw, blur0→15px; подложка#0e0e0e до opacity.33 | Одновременно700ms; контент power2.inOut, подложка power1.out |
| Передача | Обычная загрузка нового HTML, без замены DOM через AJAX | Зависит от ответа/загрузки |
| Готовность | Шрифты и важные изображения первого экрана; load/error учитываются | Не более5000ms после готовности DOM; lazy-картинки ниже и видео не ждём |
| Открытие | Графит сдвигается вниз yPercent0→100 | 700ms, power3.inOut |
| Белый слой | Вся оставшаяся подложка исчезает по прозрачности | 500ms со старта500ms, power1.out; перекрытие с графитом200ms |
| Новый контент | main: y300px→0, opacity0→1 | 1000ms, power1.out, старт350ms открытия |

Чистый уход — 700 мс, открытие с появлением — 1350 мс; между ними реальная загрузка. Значения и цвета — константы единого файла, публичных настроек времени и цвета нет. Основное содержимое берётся из первого `main`, без дополнительной обёртки. При отсутствии main работает шторка без движения контента.

## Зависимости и обычная навигация

Используется общий `window.gsap`; если он ещё не подключён к готовности DOM, файл сам загружает локальный `Modifications/vendor/gsap.min.js` относительно собственного URL. Общие CSS/JS модификаций и ScrollTrigger для самой шторки не обязательны; существующий ScrollTrigger пересчитывается после завершения. Лицензионный vendor сохранять. Vite копирует файл в сборку и добавляет одно относительное подключение.

SEO-разметка и обычные a[href] сохраняются: закрытие → location.assign → полный новый HTML. Перехватываются внутренние HTTP(S) адреса без расширения, каталоги и .html/.htm/.php; для file:// — HTML. Нет перечня разрешённых страниц. Внешние ссылки, файлы ресурсов, download, target вне _self, rel external, модификаторы клика/средняя кнопка и якоря того же документа работают обычно. Для явного исключения — `data-page-transition-skip` на ссылке. На целевой странице тоже должен быть глобальный файл, чтобы было входящее открытие.

## Проверка и API

`button[data-page-transition-preview]` или `PageTransition.preview()` показывают последовательность на месте. `PageTransition.init()` повторно безопасен; `destroy()` отменяет анимации, события, таймеры, ожидание ресурсов, снимает inert/overflow, возвращает исходные inline-свойства main и удаляет слои. Общая таблица стилей остаётся для стабильной ширины документа. Возврат из bfcache сбрасывает старое состояние и запускает открытие. После завершения отправляется document-событие `page-transition:ready`; Cookie ждёт его, если шторка занята.

Reduced motion оставляет обычную навигацию без маски и движения. Без JS страница доступна. При отсутствии/ошибке GSAP ранняя маска снимается; её аварийный таймер — 12 с, контроллер входа — 8 с. Ожидание шрифтов и важных нелени́вых изображений первого экрана ограничено 5 с; видео не ждём. Если попытка навигации не завершилась, блокировка снимается через 5 с после location.assign. Никакое хранилище не требуется. При первом получении HTML шторка может появиться только после загрузки самого файла, поэтому это локальный синхронный скрипт до CSS.

Место под вертикальную полосу постоянно резервируется через `html { scrollbar-gutter: stable; }`, включая момент снятия overflow:hidden. Не переносить правило только в busy-состояние: это вернёт сдвиг. Системные накладные полосы лишнего поля не получают.

Проверки: `node --test tests/page-transition.test.cjs tests/horizontal-gallery-input.test.cjs`; браузер — прямой вход, обновление, внутренние переходы, пример, возврат и отсутствие сдвига ширины. Обычные подключения работают также при открытии исходных HTML двойным щелчком.
