# Brodeks: два больших изображения

Самостоятельный блок страницы, не библиотечный компонент. Разметка — case.html, стили — src/styles/pages/brodeks.scss → styles.css. Размещён третьим содержательным блоком: вступление case-intro → обложка → brodeks-image-pair; хлебные крошки не считаются контентным блоком. Далее сохранён раздел «Кратко» и весь исходный контент.

Минимальная структура: section.brodeks-image-pair с доступным названием, две ссылки brodeks-image-pair__frame и по одному img. Поля от краёв экрана40px, gap20px, две равные колонки без ограничения1500px. Кадры4:3, object-fit:cover; полные изображения открываются без обрезки в просмотрщике. До767px одна колонка, поля40px и gap20px сохранены. Верхний отступ120px, до639px60px.

Настройки CSS на корне: --brodeks-image-pair-gutter:40px, --brodeks-image-pair-gap:20px, --brodeks-image-pair-ratio:4 / 3. Для замены контента менять src/href, width/height, alt и data-image-title. Сейчас используются локальные brand.webp1680×1094 и cover.webp1622×1005 из материалов Brodeks. Ресурсы не копируются в библиотеку.

Эффекты включаются независимо на каждой ссылке:

- photo-zoom — существующий общий просмотрщик по href, необязательный data-image-title. Убрать класс для обычного открытия файла браузером; чтобы полностью убрать клик, заменить a на div и удалить href.
- photo-parallax — существующая модификация движения содержимого кадра. Убрать класс для статичного изображения, размеры задаёт сам блок. Не вводить отдельный контроллер и не копировать GSAP-код.

В установленном примере оба эффекта включены на обеих картинках. Параллакс использует общий GSAP/ScrollTrigger, scale1.05 и yPercent−10→10, scrub true; появление модификации сохранено. Без JS и при reduced motion картинки доступны в обычной сетке; ссылки без JS открывают оригиналы. Есть alt, размеры, lazy/async и видимый клавиатурный фокус. Просмотрщик поддерживает Esc, возврат фокуса и блокировку фона.

Очистка/повторная инициализация при динамической замене: PhotoParallax.destroy()/init(), ImageViewer.destroy()/init() — общие API, не создавать копии для блока. В статическом HTML всё подключено автоматически. Vite преобразует href photo-zoom в пути ресурсов сборки. Не добавлять этот блок в Blocks/templates или каталог без отдельного запроса пользователя.
