# Галерея логотипов главной — clients-home

Независимый экземпляр исходного библиотечного horizontal-gallery, выбранного пользователем. Вместо прежнего статического clients установлен вторым блоком главной после hero-home. HTML — index.html, CSS — src/styles/pages/home.scss, JS/API — src/scripts/pages/home.js / HomeClientsGallery. Библиотечный компонент и галереи кейса не изменяются.

## Настройки экземпляра

Корень .clients-home[data-clients-home-gallery], уникальный ID окна clients-home-gallery; внутренние классы clients-home__viewport/track/item. Публичные data-gallery-* принадлежат скопированному контроллеру/общей модификации; корневую метку data-horizontal-gallery не добавлять, иначе будет двойная инициализация.

Установлены data-gallery-mode="scroll", data-gallery-scroll-duration="45" и data-gallery-zoom="false". Сохранены все15 оригинальных изображений и alt из images/clients. Стрелок, новых ссылок и увеличения нет. Desktop: ширина карточки220px, зазор32px, поля --page-gutter, пропорции изображений220:104. CSS --gallery-card-width/gap/padding регулируют геометрию этого экземпляра.

До959px зазор16px, ширина карточки — ширина окна минус левое поле, зазор и20px следующей карточки, как у компонента. Логотип масштабируется пропорционально, не обрезается. Галерея занимает всю ширину экрана, вне контейнера контентной колонки. Нижний отступ60px, до639px30px. После JS системная полоса скрыта.

## Движение и ввод

ScrollReel.create секции10 Modifications/modifications.js используется явно и не скопирован. Исходная последовательность повторяется бесконечно; вниз — влево, вверх — вправо. Базовый период45s, delta скролла×−.3, минимум скорости±1, переход1s expo.out — прежние параметры модификации, не дополнительные настройки экземпляра.

Mouse drag с прежней инерцией, нативный touch/тачпад, пауза при удержании, клавиатурные ArrowLeft/Right/Home/End сохранены. Видимый клавиатурный фокус останавливает автодвижение. За экраном/в скрытой вкладке/при просмотрщике цикл приостановлен. Reduced motion отключает цикл и инерцию; без GSAP остаётся ручная прокрутка, без JS — доступное нативное окно. Новых библиотек нет.

## Жизненный цикл и перенос

HomeClientsGallery.init()/destroy() повторно безопасны. Destroy убирает события/наблюдатели/rAF/инерцию, вызывает reel.destroy, удаляет повторы и восстанавливает исходное состояние. После изменения карточек/режима — destroy/init именно этого экземпляра, не общего HorizontalGallery. Исходный компонент не инициализирует clients-home. Сохранены только оригинальные карточки, служебные атрибуты и клоны не записывать в HTML.

В WordPress выводить список оригинальных логотипов с alt из медиатеки, уникальный ID окна и настройки режима; подключать JS страницы после общих модификаций. Общие зависимости: GSAP и ScrollReel, локальный styles.css. Скрипт страницы уже копируется Vite в сборку и подключён после модификаций.
